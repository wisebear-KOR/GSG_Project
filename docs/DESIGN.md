# 계시록: 말씀의 전쟁 (가제) — 기획 문서

> Chrome 내장 AI(Prompt API, Gemma 4)를 활용한 보드게임 감성의 턴제 전략 시뮬레이션.

## 1. 한 줄 요약

플레이어는 **말(계시)로만 세상을 움직이는 신**이다. 신도들(LLM)은 계시를 해석해 미플을 배치하고,
신 없이 **율법 카드**대로만 움직이는 율법파(스크립트 AI)와 보드 위에서 경쟁한다.

## 2. 핵심 설계 원칙

- **LLM은 해석과 서사만 맡는다.** 가능한 행동인지 판정, 전투, 자원 계산은 모두 JS 규칙 엔진이 한다.
- **LLM 출력은 JSON 스키마로 강제한다** (`responseConstraint`). 엔진이 한 번 더 검증하고, 규칙에 어긋나는 명령은 버린다.
- **적은 스크립트 AI다.** LLM 없이도 정상적으로 동작하고, 시드를 고정하면 결과를 재현할 수 있다.
- **턴제다.** 라운드당 LLM 호출은 약 2~3번(대사제 해석, 교리 분류, 연대기).
- 빌드 도구 없이 순수 HTML/JS로 만든다. GitHub Pages로 배포하고 MIT 라이선스를 적용한다.

### 가능성 검토에서 정한 사항

- **가능한 행동 목록 방식:** 엔진이 이번 라운드에 가능한 행동 목록(ID 포함)을 만들고,
  LLM은 그 ID 중에서만 고른다. 스키마의 `enum`으로 강제하므로 규칙에 어긋난 명령이 나올 수 없다.
  작은 모델은 좌표나 공간 판단이 약하므로 위치를 직접 고르게 하지 않는다.
- **해석 수락 / 재해석:** 실행 전에 "대사제의 해석"을 보여주고, 플레이어가 수락하거나 신앙을 내고 한 번 다시 해석하게 한다.
- **석판 모드:** Prompt API를 쓸 수 없는 환경에서는 미리 준비된 계시 카드와 규칙 기반 해석기로 플레이한다.
- **세션 관리:** 시스템 프롬프트만 담은 기본 세션을 라운드마다 `clone()`해서 쓰고, 지난 계시는 요약만 넘긴다.
- **해석기 인터페이스 분리:** 테스트할 때는 가짜 해석기로 규칙 엔진을 따로 검증한다.
- 실험 페이지: [`lab/interpret.html`](../lab/interpret.html)

## 3. 구성물

| 구성물 | 역할 |
|---|---|
| 육각 타일 보드 | 평원, 숲, 산, 강, 성지. 처음엔 뒷면이고 탐험하면 뒤집힌다 |
| 미플 | 신도 1명 = 미플 1개 |
| 행동 토큰 | 라운드마다 쓸 수 있는 행동 횟수 (4장 참고) |
| 자원 큐브 | 식량, 목재, 돌, 신앙 |
| 건물 토큰 | 마을, 신전, 성벽, 불가사의 |
| 주사위 | 전투와 선교 판정 |
| 이벤트 덱 | 매 라운드 1장 공개 (가뭄, 역병, 풍년, 떠돌이 예언자 등) |
| 기적 카드 | 신의 손패. 신앙을 소모한다 (번개, 비, 풍요 등) |
| 율법 덱 | 적의 행동 카드 (오토마) |
| 교리 트랙 | 평화, 전쟁, 풍요, 지혜 4개 트랙. 기술 트리 역할 |
| 승점 트랙 | 보드 테두리를 따라 도는 점수판 |

## 4. 행동 제한

라운드마다 할 수 있는 행동 수를 **행동 토큰**으로 제한한다. 양 진영에 같은 규칙을 적용한다.

- **기본 행동 수:** 라운드당 **3회**
- **늘리는 방법:** 신전을 짓거나 업그레이드하면 +1, 일부 교리 카드로 +1. **최대 5회**
- **미플 1개 = 행동 1회.** 행동 토큰이 남아도 쓸 수 있는 미플이 없으면 행동할 수 없다.
- **행동 칸 점유 (일꾼 놓기 규칙):** 한 칸에는 한 라운드에 미플 1개만 놓을 수 있다.
  상대가 먼저 차지한 칸은 쓸 수 없다. 배치는 비공개로 동시에 하고, 겹치면 선 플레이어가 가져간다. 선 플레이어는 라운드마다 바뀐다.
- **계시 길이 제한:** 계시는 최대 100자로 하고, 글자 수에 비례해 신앙을 소모한다. 행동 수와는 별개인 자원이다.

### 제한을 강제하는 방법

1. **스키마 단계:** 대사제 LLM의 출력 스키마에서 `orders` 배열의 `maxItems`를 현재 행동 수로 설정한다.
2. **엔진 단계:** 명령이 행동 수를 넘으면 앞에서부터 행동 수만큼만 실행한다.
   규칙에 어긋나는 명령은 무효로 처리하고, 신도가 "뜻을 헤아리지 못했다"는 연출로 보여준다.
3. **적:** 율법 카드의 우선순위 목록을 위에서부터 차례로 실행하고, 행동 수를 다 쓰면 멈춘다.

## 5. 행동 종류 (프로토타입)

| 행동 | 대상 칸 | 효과 |
|---|---|---|
| 채집 | 평원/숲/산 | 지형에 맞는 자원 획득 (식량/목재/돌) |
| 건설 | 빈 칸 또는 자기 칸 | 자원을 써서 건물 건설 |
| 기도 | 신전 | 신앙 획득 |
| 선교 | 적 마을 인접 칸 | 주사위 판정. 성공하면 적 미플 1개를 개종시킴 |
| 공격 | 적 칸 인접 | 주사위 전투. 이기면 칸 점령 |

## 6. 라운드 진행

```
① 이벤트    이벤트 카드 1장 공개
② 계시      플레이어가 계시 작성 (신앙 소모) + 기적 카드 사용 가능
③ 해석      대사제 LLM이 계시를 해석해 명령 JSON 생성 (행동 수 이하)
            율법파는 율법 카드를 뽑고 스크립트로 배치
            양쪽 배치는 뒷면으로 숨김
④ 공개/해결  동시 공개 → 채집 → 건설 → 선교 → 전투 순으로 해결
⑤ 유지      식량 소비, 인구 증가, 교리 트랙 이동, 선 플레이어 교체
⑥ 연대기    LLM이 이번 라운드 일을 경전 한 구절로 기록
```

### 대사제 출력 스키마 (초안)

```json
{
  "type": "object",
  "properties": {
    "interpretation": { "type": "string", "maxLength": 80 },
    "orders": {
      "type": "array",
      "maxItems": 3,
      "items": {
        "type": "object",
        "properties": {
          "meeple": { "type": "integer" },
          "action": { "enum": ["gather", "build", "pray", "preach", "attack"] },
          "tile": { "type": "string" },
          "building": { "enum": ["village", "temple", "wall"] }
        },
        "required": ["meeple", "action", "tile"]
      }
    }
  },
  "required": ["interpretation", "orders"]
}
```

`maxItems`는 현재 행동 수에 맞춰 라운드마다 바꾼다.

## 7. 교리 트랙 (기술 트리)

- 계시를 내릴 때마다 LLM이 계시를 평화, 전쟁, 풍요, 지혜 중 하나로 분류하고 해당 트랙이 1칸 오른다.
- 트랙의 특정 칸에 도달하면 교리 카드를 얻는다. 예: 전쟁 3단계 "성전의 맹세"는 공격 주사위 +1, 지혜 2단계는 행동 수 +1
- 평소 어떤 계시를 내렸는지가 문명의 성격을 정한다.

## 8. 적: 율법파 (오토마)

- 매 라운드 율법 카드를 1장 뽑고, 카드의 우선순위 규칙을 행동 수만큼 위에서부터 실행한다.
- 덱 구성으로 성격을 정한다 (공격형, 확장형, 신앙형).
- 난이도: 어려움은 2장을 뽑아 더 유리한 쪽을 쓰고, 시작 자원 보너스를 준다.

```js
{
  id: 'law-07', name: '확장',
  rules: [
    { if: s => s.adjacentEmpty('plain'), do: 'build', target: 'village' },
    { if: s => s.res.wood < 3,           do: 'gather', target: 'forest' },
    { do: 'pray' },
  ],
}
```

## 9. 신앙과 이단

- 계시가 앞선 계시와 모순되거나 신도를 죽음으로 몰면 신앙이 떨어진다.
- 신앙이 0이 되면 미플 1개가 이단으로 떨어져 나가거나 율법파로 넘어간다.

## 10. 승리 조건

- 정복: 적 수도 신전 점령
- 신앙: 보드 전체 인구의 과반 개종
- 불가사의: 대성당 완공
- 승점: 12라운드 종료 시 승점이 가장 높은 쪽

## 11. 페이지 구조

```
[시나리오 고르기] → [시나리오별 페이지] → [보드 플레이] → [승리/달성]
```

- 1장 "첫 계시": 튜토리얼. 적 없이 마을을 키운다.
- 2장 "이웃의 불신자": 율법파가 처음 등장한다.
- 시나리오마다 맵, 시작 조건, 승리 조건, 특별 규칙이 다르다.

## 12. 프로토타입 범위 (1차)

- 5×5 육각 보드, 행동 5종, 행동 제한 3~5회
- 이벤트 카드 6장, 율법 카드 8장, 교리 트랙 4종
- 시나리오 1개로 한 판을 끝까지 플레이할 수 있게 만든다
- 확인할 것: 한 라운드에 걸리는 시간, 계시 해석이 재미있게 어긋나는지
