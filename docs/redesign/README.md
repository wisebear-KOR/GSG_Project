# 재설계 — 칸의 값과 배치 점수 (2026-10-03 시작)

전략층을 다시 짜서 깊이를 더한다. 말의 층(해석기·테마)은 강점이니 지킨다.
출발점은 [HANDOFF-2026-10-03.md](../HANDOFF-2026-10-03.md)의 진단이다 (main 작업 트리에 아직 커밋 안 됨).
평가 점수는 66~67에서 멈췄고, 원인은 **같은 종류의 칸은 값이 같다**는 것이었다.
숙련 봇의 칸을 같은 종류 안에서 무작위로 옮겨도 승률이 2~5점만 떨어진다.

## 1. 용어

| 용어 | 정의 | 누가 다루나 |
|---|---|---|
| **절대 가치** | 그 칸 혼자서 주는 자원과 양. 지형·특징 × 활성도 단계 | 엔진이 결정적으로 계산하고, 판 위에 늘 보인다 |
| **상대 가치** | 지금 판에서 플레이어가 매기는 그 칸의 값. 이어짐, 시점, 율법파와의 다툼 같은 것 | 플레이어의 머릿속에만 있다. 게임은 계산하지 않고 판단할 재료만 보여 준다 |
| **배치 점수** | 해석기가 후보 칸마다 매기는 점수. 계시의 말과 얼마나 맞는가 | 엔진의 배치 점수 함수 하나. 해석기는 의도와 장소 표현만 넘긴다 |

**배치 점수의 재료**

1. **말과의 맞음 (주)** — 짚은 칸·이름·지형·방향·"노리는 곳"·"쉬던 땅" 같은 장소 표현.
2. **기본값 (부)** — 말이 칸을 가르지 못할 때만 쓴다. 세기는 난이도로 정한다. 예: 쉬움은 절대 가치가 큰 칸, 어려움은 가까운 칸.
3. **넣지 않는 것** — 플레이어가 말하지 않은 전략 판단. 예: 모자란 자원부터, 이길 확률이 높은 칸부터.
   단, 플레이어가 "약한 마을을"처럼 말로 짚으면 그것은 1번(말과의 맞음)이 된다.

**실력 = 내 상대 가치를 말로 배치 점수에 옮기는 능력.** 확인 화면은 둘의 차이를 보여 주어, 다음에 더 정확히 말하도록 가르친다.

## 2. 원칙

1. **결정은 말로 하기 좋은 것에 둔다**: 의도·우선순위·조건·모양·시점 (HANDOFF §3.1).
2. **칸의 값은 해석기가 혼자 판단할 수 없는 것에서 나온다** (HANDOFF §3.2). 그래서 배치 점수에는 말과의 맞음만 넣는다.
   연결 실험에서 기본 배치가 "이어지는 칸 먼저"를 알자 눈먼 대본이 숙련의 ~10점 안으로 들어왔다 — 기본값이 똑똑해지면 깊이가 다시 사라진다.
3. **깊이를 하나 더할 때마다 땜질 규칙 하나를 걷어낸다** (HANDOFF §3.3).
4. **측정으로 정한다**: HANDOFF §3.4의 넷 — 칸 무작위 손실, 숙련 − 가장 센 눈먼 대본, 대차 비율, 두 장 앞보기 이득 — 에 하나를 더한다.
   (e) 같은 칸을 되풀이하는 대본의 손실.
5. **해석기는 바꿔 끼울 수 있게 한다**: 석판·Gemma·나중의 작은 모델이 같은 의도 형식을 내고, 칸 고르기는 엔진 한곳(배치 점수)에서 한다.
   상업 배포를 위한 작은 모델 구성은 이 계약 위에 얹는다 ([DECISION-MODELS-2026-10-03.md](../DECISION-MODELS-2026-10-03.md)).
6. **규칙 변경은 사용자가 정한다**: 잰 선택지를 보이고, 묻지 않고 넣지 않는다.

## 3. 후보 규칙

| 후보 | 한 줄 | 상태 |
|---|---|---|
| **활성도** | 쓴 칸은 지치고, 쉬면 회복한다. 절대 가치가 장마다 바뀐다 | 이번 재설계의 중심. **모양을 정함 (§5.1)** |
| 연결 | 수도에서 제 건물로 이어진 마을만 센다 | HANDOFF 4.1, 가장 유망. 배치가 38점을 가른다 |
| 율법 카드의 빈틈 | 카드마다 그 장 우리 공격이나 선교 +1 | HANDOFF 4.2, 보정 필요 |
| 두 표식 점령 | 마을은 공격 승리 표식 둘에 넘어온다 | HANDOFF 4.3, 사용자 보류 |
| 에워싸기 · 모임 | 이웃을 쥐면 넘어온다 · 붙은 마을 +1 | HANDOFF 4.4, 아직 안 잼 |

**활성도에 대한 메모** (의견, 아직 안 잼)

- 줄어들기만 하면 "가장 덜 지친 칸"이라는 한 수 탐욕으로 풀린다. **회복**(쉬면 돌아오거나, 묵히면 덤)이 있어야 "언제"라는 결정이 생기고 앞보기 이득이 커진다.
- 표시는 세 단계(기름짐 / 보통 / 지침) 정도로 단순하게 한다. 칸마다 숫자가 장마다 바뀌면 관리가 무겁다.
- 지금 "되풀이"(읽힘)는 거두고 기도하는 살림을 예외로 둔다 (`economyOnly`, engine.js:817). 활성도는 그 빈자리를 땅이 메운다 — 읽힘을 가볍게 할 후보.
- 테마: 안식년(일곱째 해에는 땅을 쉬게 하라). "지친 땅은 쉬게 하라", "묵은 땅을 일궈라"처럼 말로 하기 좋다.
- 티켓 074는 칸 위 수확량 숫자를 "미리보기와 겹친다"며 폐기했다. 칸마다 값이 달라지면 그 이유가 사라진다.

## 5. 정한 것

### 5.1 활성도 (2026-10-03, D1·D2·D5)

사용자의 첫 번째 안(풍요/정상/빈곤 세 단계)을 바탕으로, 회복은 확정적으로 하고 무작위는 풍요에만 두었다.

1. **쓰면 지친다** — 채집한 땅은 장이 끝날 때 한 단계 내려간다 (풍요 → 정상, 정상 → 빈곤, 빈곤은 그대로).
2. **쉬면 낫는다** — 아무도 채집하지 않고 쉰 빈곤 땅은 정상으로 돌아온다 (풍요까지는 오르지 않는다).
3. **풍요는 하늘이 준다** — 사건과 기적으로만 생기고, 한 장 앞서 예고된다.

| 땅 | 풍요 | 정상 (지금 값) | 빈곤 |
|---|---|---|---|
| 평원 (식량) | 3 | 2 | 1 |
| 숲 (나무) | 3 | 2 | 1 |
| 산 (돌) | 3 | 2 | 1 |
| 강 (식량) | 2 | 1 | 0 |
| 언덕 (신앙) | 2 | 1 | 0 |
| 오아시스 · 채석장 | 4 | 3 | 2 |

| 항목 | 정한 것 |
|---|---|
| 지치게 하는 일 | **채집만**. 우리 마을 칸에서 하는 채집도 센다. 건설·탐험·기도·선교·공격은 세지 않는다 |
| 바뀌는 때 | 장 끝 한 번 (해결과 유지 뒤). 다음 장의 판·행동 글·미리보기가 새 값을 보인다 |
| 회복과 난이도 | 회복에 필요한 휴식 — 쉬움·보통 한 장, 어려움 두 장 |
| 풍요가 생기는 길 | **땅의 운 덱** (§5.2) — 풍년·가뭄을 사건 덱에서 옮겨 와 칸 단위로 바꾼다. **기적**: 단비를 말로 짚은 땅("단비를 동쪽 들판에")에 |
| 율법파 (D2) | 같은 규칙. 땅의 상태는 양쪽이 함께 쓴다 — 율법파가 쓴 중립 땅은 우리에게도 지친 땅이다. 율법파의 채집은 "닿는 첫 칸" 대신 닿는 땅 가운데 가장 기름진 칸 |
| 기본 배치 (D5) | 활성도를 보지 않는다 — 지금의 "양 많은 칸 먼저"(`rankMatches` R4)를 지운다. 쉬움만 덜 지친 칸을 먼저 고른다 |
| 말로 짚기 | 새 장소 말 "쉬던 땅", "기름진 곳" (N5). 확인 화면 칩에 "지친 땅 — 식량 +1" |
| 표시 | 칸마다 세 단계 표식 하나, 툴팁에 "지침 — 한 장 쉬면 정상" |
| 조정할 값 | 단계별 양, 휴식 길이, 땅의 운이 바꾸는 칸 수 — 1단계 실험에서 잰다 |

**견준 안** — 사용자가 낸 세 안을 견주고, 1안을 뼈대로 둘째·셋째의 좋은 점을 섞었다 (§5.2).

| | 1안: 세 단계 | 2안: % + 주사위 | 3안: 늘 무작위 |
|---|---|---|---|
| 내용 | 풍요/정상/빈곤, 쓰면 한 단계 내림 | 활성도를 %로, 오르내림을 주사위로 | 모든 칸이 늘 무작위 활성도 |
| 내 선택이 땅을 바꾸나 | 예 (쓰면 지침, 쉬면 회복) | 예, 폭은 운 | 아니요 |
| 앞을 볼 이득 | 생긴다 | 줄어든다 | 없다 |
| 운의 몫 | 풍요만 | 는다 — 지금도 승패 분산의 60~80%가 주사위다 | 크게 는다 |
| 말로 하기 | 기름진·지친·쉬던 땅 | 어렵다 ("73%짜리 숲") | 칸 번호 위주 |
| 규칙 무게 | 가볍다 | 무겁다 — 자원이 정수라 %는 숨은 반올림 문턱이 된다 | 가볍지만 판이 매 장 시끄럽다 |
| 가져온 것 | 뼈대 | "땅의 운"을 덱으로 (주사위 대신, 미리 보이게) | "매 장 좋은 곳이 바뀐다"를 빈도로 |

### 5.2 땅의 운 덱 (2026-10-06)

풍요와 빈곤을 만드는 새 덱이다. 사건 덱과 따로 둔다 — 사건은 부족의 일, 땅의 운은 땅의 일.

| 항목 | 정한 것 |
|---|---|
| 뽑기 | 장마다 한 장. 다음 장 카드가 한 장 앞서 보인다 (다음 장 율법 카드·사건 예고와 같은 결) |
| 놓는 곳 | 카드가 말한 지형의 칸 가운데 **점대칭인 두 칸**에 함께 — 양쪽에 공평하고, 가운데 땅을 두고 다툼이 생긴다 |
| 카드 예 (구성은 1단계에서 정한다) | 풍년 — 들판(평원·강) 두 곳 풍요 · 숲의 은혜 — 숲 두 곳 풍요 · 가뭄 — 들판 두 곳 빈곤 · 고요 — 변화 없음 |
| 빈도 (3안의 맛) | 한 장에 바뀌는 칸 수와 고요 카드의 비율이 "매 장 좋은 곳이 바뀐다"의 손잡이. 막이 갈수록 거칠게 할 수도 있다 |
| 장마다 몇 장 | 한 장으로 시작해 1단계 실험에서 잰다 (제안) |

**옮기면서 바뀌는 것**

| 곳 | 지금 | 바뀜 |
|---|---|---|
| 사건 덱 `EVENTS` (D:108-115) | 평온·가뭄·풍년·역병·위협·예언자 6종, 6장씩 돌린다. 3막은 평온을 뺀다 | 가뭄·풍년이 빠져 4종 (3막은 3종). 덱 구성과 장수를 다시 맞춘다 — 새 사건이 필요할 수 있다 |
| `gatherAmount` 보정 (E:368-369) | 가뭄 식량 −2 (단비면 없음), 풍년 평원·강 +2 | 지운다. 칸의 단계가 대신한다 |
| 청원 (E:695) | 가뭄이면 식량 청원 | 땅의 운 가뭄 카드, 또는 우리 들판이 빈곤일 때로 |
| 기적 단비 (D:120, E:866) | 식량 +3, 이번 장 가뭄을 없앤다 (`rainActive`) | 말로 짚은 땅을 풍요로. 가뭄으로 빈곤해진 땅을 되살리는 쓰임도 함께 |
| 지혜 궁극 (다가올 사건 둘 중 고르기) | 사건 6종에서 | 4종에서 — 고를 맛이 줄어드는지 본다 |
| 튜토리얼 사건 순서 (D:388) | 3장에 풍년 | 땅의 운 카드로 옮기거나 다른 사건으로 |
