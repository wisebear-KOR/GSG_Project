# 계시 해석기 실험 기록

실험 페이지: [`lab/interpret.html`](../lab/interpret.html)
환경: Chrome 154 (Canary), 내장 Gemma 4, 한국어 프롬프트, 행동 수 제한 3, 계시당 3회 반복.

## 결과 요약

| 버전 | 세트 | 의도 적중 | 교리 적중 | 기도 선택률 | 평균 응답 | 비고 |
|---|---|---|---|---|---|---|
| v1 | 기본 | 80% | 70% | 90% | 2.1초 | 설명투, 기도로 칸 채우기 |
| v2 | 기본 | 100% | 100% | 47% | 1.8초 | 장소별 묶음, 자동 채우기 |
| v3 | 기본 | 90% | 100% | 40% | 1.6초 | "산을 두려워하라"에 채석 3/3 |
| v3 | 심화 | 93% | 85%* | - | 1.8초 | "숲을 베지 마라"에 숲 채집 2/3 |
| v4 | 기본 | 100% | 96% | 47% | 1.5초 | forbidden 칸 추가 |
| v4 | 심화 | 93% | 81% | 71% | 2.0초 | 예시 문장 복사 2건, 목록 기호 7건 |
| v5 | 기본 | 87% | 100% | 40% | 2.3초 | 같은 장소 충돌로 공격이 빠짐 2건 |
| v5 | 심화 | 93% | 100% | 50% | 2.5초 | 목록 기호 0건, 예시 복사 0건 |

\* 복수 정답 기준으로 다시 계산한 값. 반복이 3회뿐이라 버전 간 ±10%p 차이는 잡음일 수 있다.

## 확인된 사실

- **JSON 스키마 강제(`responseConstraint`)는 매우 안정적이다.** 수백 회 실행에서 JSON 파싱 실패 0건.
- **`uniqueItems`는 지원되지 않는다.** 스키마에 넣으면 요청 자체가 `NotSupportedError`로 거부된다.
- **enum에 한국어 값은 쓸 수 있다.** 한국어 교리 값(평화/전쟁/풍요/지혜)이 정상 동작한다.
- **모델이 가끔 `UnknownError`로 실패한다.** 같은 요청을 다시 보내면 대부분 성공하므로 재시도 1회가 필요하다.
- **Chrome은 한국어 출력을 공식 지원하지 않는다** (지원 목록: de, en, es, fr, ja). 언어 지정 없이 세션을 만들면
  한국어로 잘 생성되지만 콘솔에 경고가 뜬다.
- **부정문은 별도 칸으로 받아야 한다.** v4에서 추가한 `forbidden` 칸 이후 "숲을 베지 마라"를 3/3으로 올바르게 처리했다.
  다만 "두려워하라"처럼 약한 부정은 여전히 놓칠 때가 있다.
- **금지 표현 목록은 역효과가 난다.** "해석됩니다"를 쓰지 말라고 하자 그 표현이 그대로 나왔다.
- **완성된 예시 문장은 통째로 복사된다.** 행동과 무관한 소재로, "다른 계시였다면"이라는 틀을 씌워야 한다.
- **모호한 계시는 최근 사건으로 해석된다.** "떠돌이의 말을 믿어라"와 예언자 사건은 탐험을 거의 항상 맞혔다.

## 게임 설계에 반영할 것

- 해석기 출력: `interpretation`, `forbidden`, `orders`, `doctrine` (이 순서로 생성)
- 엔진이 `forbidden`을 선택 결과와 자동 채우기에서 모두 제외
- **같은 장소 충돌**은 프롬프트로 해결되지 않는다 (5~10%). 엔진이 해결한다:
  같은 장소의 행동이 둘이면 `doctrine`과 맞는 행동을 남긴다 (예: 전쟁 교리 → 공격 우선).
  또는 행동 칸 설계에서 같은 장소에 성격이 다른 행동을 몰아넣지 않는다.
- 모델 실패 시 재시도 1회, 그래도 실패하면 석판 모드 해석기로 대체
- 프롬프트 튜닝은 수확 체감 구간에 들어섰다. 이후 개선은 엔진 규칙과 행동 데이터 설계로 한다.
