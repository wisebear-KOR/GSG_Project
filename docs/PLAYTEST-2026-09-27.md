## 단계별 분석

### 1. 계시 쓰기 — 신앙 경제가 게임을 망가뜨린다 (치명)

- 계시는 25자마다 신앙 1~4를 쓰는데, **신앙 수입은 신전 1단계에서 +0**이다. 수입원은 기도뿐이다.
- 신앙이 0이면 계시를 못 한다. 판단형은 5~12라운드, 전쟁형은 7~12라운드 내내 침묵했다.
- 게다가 **신앙 0이면 매 라운드 신도 1명이 율법파로 넘어간다.** 판단형 9명, 전쟁형 7명이 넘어갔고,
  율법파 인구는 3 → 11로 불었다. 한 번 0이 되면 회복할 방법이 없는 죽음의 소용돌이다.
- 침묵할 때의 자동 노동은 기도를 하지 않는다 (가장 부족한 자원 채집만).
- 결과적으로 **"합리적으로 말하는 신"이 지고, 우연히 기도가 섞인 신이 이긴다.** 규칙이 화면에 드러나지 않아 플레이어는 이유를 알 수 없다.

### 2. 대사제 해석 (LLM) — 뜻은 잘 잡지만 말이 길고 행동과 어긋난다

좋은 점
- LLM 응답 2.7~3.5초, 오류 0, 형식 깨짐 0.
- 은유 해석이 좋다: "손을 펴라" + 예언자 사건 → 안개 두 곳 탐험, 보물 발견 / "겨울이 온다" → 목재·식량 비축과 기도 /
  "침묵하는 자가 이기리라" → 성벽과 기도 / "굶주린 자가 없게 하라" → 기도·탐험·수확.

문제
- **해석문이 길다**: 중앙값 87자(목표 50자), 100자 초과 8/34, 1건은 140자 상한에 잘려 문장이 끊겼다.
- **어미 찌꺼기**: "택하라! 도다!", "본도다", "중요도다", "되살려라 도다" 등 34건 중 10건(29%).
- **말과 행동의 불일치**: "성벽을 쌓고 창을 벼려라" → 실제로는 마을 건설 (성벽을 지을 돌이 없었다) /
  "높은 곳에 제단을 세워라" → 마을 2개. 해석문이 행동보다 먼저 생성되기 때문이다 (스키마 순서가 해석문 → 행동).
- 좌표를 말한다: "산 C1에 돌을 새겨라". 계시와 무관한 사건 얘기를 먼저 한다: "안개 속에 보물이 있도다!".
- 건설 과다 주문: "마을을 넓혀라"류에서 감당 못 할 마을을 2~3개씩 주문 → "자원 부족" 거부 9건.

### 3. 해석 확인과 배치

- **확인 버튼까지 중앙값 7.4~9.6초, 최대 11.3초**. LLM은 3초인데 나머지는 연출이다:
  인장·빛기둥 연출(약 2.3초)이 끝난 **다음에** LLM을 부르고(순차), 해석문 87자를 타자기로 쓴다(약 3초).
- 첫 라운드는 세션 생성 때문에 13초.
- 표시 수치가 실제와 다르다: 가뭄 때 "강에서 물고기를 잡는다 (식량 +0)"이 실제로는 +1 (교리 보너스가 계시 기록 **후**에 반영).

### 4. 공개와 해결 — 적과 만나지 않는다 (치명)

- 4판 중 **3판에서 율법파와 한 번도 닿지 않았다.** 공격은 4판 모두 0회.
- **시야가 넓어지지 않는다**: 탐험하지 않으면 밝혀진 칸은 끝까지 7칸. 전쟁형 판에서 율법파가 우리 땅 바로 옆(B1, C3)에 마을을 세웠는데도 안개 속이라 보이지 않았고, 공격·선교 대상도 되지 않았다.
- 율법파는 반대쪽(A열)으로 확장하는 경우가 많고, 두 수도 사이가 멀다.
- 선 플레이어 규칙으로 자동 노동이 막힌 경우가 4건 (자동 노동이 경합 칸을 고른다).
- 율법파는 신앙을 쓰지 않고 쌓기만 해서(최대 28) **선교 방어 +1이 영구적으로** 붙는다.

### 5. 유지 — 신도 수의 이점이 불명확하다

- 신도 수가 하는 일: 식량 1씩 소비, 승점 2점. **행동 수는 신전 단계로만 정해져서 신도가 늘어도 행동은 3회 그대로다.**
- 그래서 신도는 "먹기만 하는 점수 토큰"이다. 평화형은 신도 10명이 되자 식량이 바닥나 굶주렸다.
- 인구는 식량 여유가 있으면 자동으로 늘어나 조절 수단이 없다.
- **플레이어는 4판 모두 신전을 한 번도 높이지 못했다** (돌이 늘 0~2, 신전 비용 돌 3). 율법파는 1~2회 높여 행동 5회.
- 판단형은 끝에 식량 28, 목재 16, 돌 20을 쥐고 있었다. **말을 못 하면 자원을 쓸 방법이 없다.**

### 6. 승패

- 모든 판이 승점으로 끝났다. 정복·신앙(인구 3/4)·대성당 승리는 도달 가능한 거리에 없었다.
- 승점 = 신도×2 + 마을×3 + 신전×2 + 수도 내구도라서, 사실상 **인구와 마을 수 경쟁**이다.

### 7. 기타

- **배포 후 옛 파일 캐시**: 브라우저가 이전 `style.css`·`fx.js`를 계속 써서 새 연출이 안 보였다 (강력 새로고침 필요).
  GitHub Pages는 10분 캐시를 건다. 파일 버전 쿼리나 import map으로 해결해야 한다.

## 개선 제안 (우선순위)

### P0 — 게임이 성립하게

1. **신앙 경제 재설계**
   - 매 라운드 기본 신앙 수입(예: +1, 신도 3명당 +1 추가) → "말할 수 있음"을 기본값으로
   - 계시 비용을 1~2로 낮추고 길이 영향 완화, 긴 계시는 교리 +2 같은 보상으로
   - 이단은 "신앙 0이 2라운드 연속"일 때만, 첫 라운드는 경고
   - 침묵 시 자동 노동에 기도 포함 (신앙이 낮으면 기도 우선)
   - 신앙이 2 이하면 UI에서 강하게 경고 ("다음 장에는 말할 수 없다")
2. **시야**: 우리 영토와 인접 1칸은 항상 보인다. 적이 우리 사거리 안에 건설하면 즉시 공개.
3. **접촉 보장**: 시나리오 1의 두 수도 거리를 줄이거나, 가운데에 서로 탐내는 성지를 두고 율법파 오토마가 그쪽으로 확장하게.
4. **신도 수의 의미** (사용자 제안 3)
   - 행동 수 = min(신도 수, 신전 한도) 대신 **신도 2명당 행동 1** 같은 식으로 인구가 행동을 늘리게
   - 전투·선교에 **수적 우세 보너스** (인접한 우리 신도가 많을수록 +1)
   - 신도 3명당 신앙 +1 (기도하는 무리)
   - 인구 증가를 자동이 아니라 "마을에 식량 여유가 있을 때 선택"으로 하거나 증가 속도를 마을 수에 묶기

### P1 — 대사제 품질과 속도

5. **스키마 순서를 행동 → 해석문**으로 바꿔 말과 행동을 일치시킨다. 해석문 60~80자 상한, 문장 2개 이하.
6. 어미 후처리: 문장 끝의 떠도는 "도다"를 정리, 좌표 표기 제거.
7. **연출과 LLM 호출을 병렬로**: 인장·빛기둥이 도는 2.3초 동안 LLM을 미리 부른다 → 확인까지 약 3초 단축.
   타자기 속도 2배, 첫 세션은 메인 화면에서 미리 준비.
8. 남는 자원의 쓸 곳: 제물(자원 → 신앙), 신전 비용에서 돌 부담 완화.

### P2 — 다듬기

9. 표시 수치를 실제 보너스와 일치 (교리 보너스를 계시 전에 미리 반영해 표시)
10. 자동 노동이 선점당할 칸을 피하게
11. 배포 캐시 무효화
12. 율법파 신앙 소비처(교화에 신앙 소모) 추가해 선교 방어 영구 보너스 해소

## 이미 반영한 사용자 피드백 (같은 날)

- 계시 버튼: 날아가는 인장 → **두루마리 위에서 들렸다 쾅 찍히는 도장**, 인주 자국이 남음
- 빛기둥: 반투명 막대 → **광선 다발 + 겹겹의 빛기둥 + 나선 입자 + 원근 충격파 + 타일 축복 물결** (캔버스 가산 합성)
