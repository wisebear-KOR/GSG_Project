# 알려진 문제와 이식 때 정할 것

명세를 쓰면서 찾은 **현재 웹판의 이상한 동작·버그·불확실한 점**을 한곳에 모았다. 자세한 근거(파일:줄, 실행 확인)는 각 명세의 "확인 필요" 절에 있다.

## 원칙: 먼저 똑같이, 그다음 같이 고친다

골든 테스트([export/golden](../export/golden/README.md))는 **지금 웹판의 동작**을 기록했다. 그래서 이식은 버그까지 그대로 재현해 골든을 전부 통과시킨 뒤, 고칠 것을 골라 **JS와 GDScript를 함께 고치고 골든을 다시 만든다** (`node tools/golden.mjs`). 이식 중에 한쪽만 고치면 차이가 버그인지 이식 실수인지 구별할 수 없다.

## A. 규칙 — 재현 후 고칠지 정할 것 ([02 §19](../spec/02-rules.md#19-확인-필요))

| # | 현재 동작 | 제안 |
|---|---|---|
| A1 | 선 진영이 자기 수도에서 기도·신전을 하면 같은 장 상대의 그 수도 공격·선교가 **칸 막기**로 막힌다 | 수도 칸은 막기에서 빼는 것을 검토 (밸런스 영향 큼 → 퍼징으로 확인) |
| A2 | `validateOrders`가 같은 칸의 행동을 교리 우선 행동으로 바꿀 때 **예산을 다시 계산하지 않는다** (자원 하나로 마을 둘이 받아들여지고 해결 때 하나 실패) | 고친다 |
| A3 | 안식일·"굶기지 말라" 계명을 새긴 장에 **건설 외 명령이 전부 빠진다** (`main.js:714-715`, `undefined` 비교) | 고친다 (명백한 버그) |
| A4 | 난민 행렬 갈림길에 무료 선택이 없어 **식량·신앙이 음수**가 될 수 있다 | 음수 방지 또는 무료 선택 추가 |
| A5 | 신도 수 우위(+1 주사위)가 주석과 달리 **공격에만** 적용 | 의도 확인 후 주석 또는 규칙 정리 |
| A6 | 가뭄이 문구("평원·강")와 달리 **모든 식량 채집**(오아시스 포함)에 적용 | 문구를 맞춘다 |
| A7 | 4×4·7×7에서 성지가 가운데 언덕이 아니고, 7×7에서 성지가 발견지와 겹칠 수 있다 | 검토 |
| A8 | 3막 보충 덱에 `calm`이 다시 들어갈 수 있다 | 검토 (드묾) |
| A9 | 소명의 장 문턱이 8장짜리 판에서도 같다 | 판 길이에 비례시키는 것을 검토 |
| A10 | 선교 성공·평화 궁극·이탈은 인구 한도를 보지 않는다 | 의도 확인 |
| A11 | 율법파 계획이 같은 비용 행동 둘을 계획해 한쪽이 실패할 수 있다 | 검토 |
| A12 | 해결 직후 저장·불러오기하면 유목민 선택이 사라지고 이후 유목민도 막힌다 | 고친다 |
| A13 | 번개로 율법파 수도를 쳐도 내구도가 줄지 않는다 | 의도 확인 |
| A14 | 승천 1의 식량 +4가 설명에 없다, 저주 말투의 신앙 −1은 공격 없이도 낸다 | 문구 정리 |
| A15 | 율법 석판 패배가 에필로그에서 "승점에 밀림"으로 분류된다 ([07](../spec/07-progression.md#확인-필요)) | 전용 문구 추가 |

## B. 해석기 ([05 확인 필요](../spec/05-interpreter.md#확인-필요))

| # | 현재 동작 | 제안 |
|---|---|---|
| B1 | LLM 호출에 **타임아웃이 없다** — 모델이 멈추면 해석 화면에 갇힌다 | Godot 판은 타임아웃 → 석판으로 대체 (필수) |
| B2 | 모델 다운로드 진행률이 표시되지 않을 수 있다 | Godot에서 LLM을 쓸 때 진행률 UI를 새로 설계 |
| B3 | 석판은 규칙마다 **첫 후보 하나만** 명령으로 만든다 ("곡식을 네 번 거두라" → 하나) | 재현. 고치면 밸런스가 바뀐다 |
| B4 | `~지 말고`는 부정으로 보지 않는다 ("숲을 베지 말고 돌을 캐라" → 숲 채집) | 검토 |
| B5 | 침묵도 청원 외면으로 센다 / 예언 "무너지리라"는 선교로 넘어온 마을을 세지 않는다 | 의도 확인 |
| B6 | 글자 수를 UTF-16 단위로 센다 (이모지 = 2) | 재현하거나, 양쪽을 코드 포인트로 바꾸고 골든 재생성 |

## Godot에서 첫날 확인할 것

- `RegEx`에서 `\p{Hangul}`, `[가-힣]`, `(*UCP)\s`가 기대대로 동작하는지 ([05 §6](../spec/05-interpreter.md#6-godot-이식-메모)).
- JSON 숫자가 float로 들어오는 문제: 시드 같은 정수는 `int()`로 바꾼 뒤 해시·난수에 넣는다 (`"2026.0"`으로 문자열화되면 해시가 달라진다).
- SVG 가져오기가 필터(그림자·종이 질감)를 무시하는지 — 무시하면 `docs/export/svg/index.html`에서 PNG로 받아 쓴다.
- 한국어 자동 줄바꿈(`keep-all`처럼 어절 단위)이 `Label`/`RichTextLabel`에서 되는지.
