## 원칙: 먼저 똑같이, 그다음 같이 고친다

골든 테스트([export/golden](../export/golden/README.md))는 **지금 웹판의 동작**을 기록했다. 그래서 이식은 버그까지 그대로 재현해 골든을 전부 통과시킨 뒤, 고칠 것을 골라 **JS와 GDScript를 함께 고치고 골든을 다시 만든다** (`node tools/golden.mjs`). 이식 중에 한쪽만 고치면 차이가 버그인지 이식 실수인지 구별할 수 없다. 아래에서 고친 항목은 골든도 이미 새 동작으로 다시 만들어졌으므로 **새 동작**을 재현하면 된다.

## Godot에서 첫날 확인할 것

- `RegEx`에서 `\p{Hangul}`, `[가-힣]`, `(*UCP)\s`가 기대대로 동작하는지, 석판 사전의 뒤보기 — 갈래끼리 길이가 다른 `(?<!돌아|들어|나)`, 긍정 뒤보기 `(?<=[가-힣]되|[가-힣]고|[가-힣]며|[가-힣]면서|[가-힣]듯) `(`87a0fce`, `되` 갈래는 `bcdeb22`, `듯` 갈래는 `b470e03`) 포함 — ·앞보기 `(?!…)`가 되는지(1195문장 회귀 시험을 그대로 돌리면 한 번에 본다). 언어팩의 객체 값(`kw.place.terrainName`·`kw.place.dir`)이 JSON에서 `Dictionary`로 읽히는지 ([05 §6](../spec/05-interpreter.md#6-godot-이식-메모)). 메아리의 `[\s\p{P}]`는 JS `\s`가 유니코드 공백을 포함하므로 `[\s\p{Z}\x{FEFF}\p{P}]`처럼 옮긴다 ([02 §20](../spec/02-rules.md#20-godot-이식-메모)).
- JSON 숫자가 float로 들어오는 문제: 시드 같은 정수는 `int()`로 바꾼 뒤 해시·난수에 넣는다 (`"2026.0"`으로 문자열화되면 해시가 달라진다).
- SVG 가져오기가 필터(그림자·종이 질감)를 무시하는지 — 무시하면 `docs/export/svg/index.html`에서 PNG로 받아 쓴다.
- 한국어 자동 줄바꿈(`keep-all`처럼 어절 단위)이 `Label`/`RichTextLabel`에서 되는지.
