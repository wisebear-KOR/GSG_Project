# 언어팩 (i18n)

게임에 나오는 모든 글은 `js/game/i18n/` 아래 언어팩에 모여 있다. 코드에는 키만 남는다.

```
js/game/i18n.js          t(key, vars) · lang · LOCALES · setLang
js/game/i18n/ko.js       한국어팩 (기준). 아래 조각을 합친다
js/game/i18n/ko/
  grammar.js             한국어 조사 도우미 josa()
  ui.js                  화면: main.js · index.html
  shell.js               연출·보드·소리·그림: fx.js · board.js · sound.js · art.js
  engine.js              진행 기록(로그)·판정 문구: engine.js · mapgen.js · meta.js
  data.js                카드·사건·지도자·기적 등 데이터: data.js
  interp.js              해석기: 대사제 프롬프트, 석판(키워드) 사전, 말투 탐지: interpreter.js · lore.js
  story.js               연대기·에필로그·업적·튜토리얼: chronicle.js · tutorial.js
tools/i18n-check.mjs     코드에 남은 한글, 언어팩끼리 빠진 키를 찾는다
```

## 쓰는 법

```js
import { t } from './i18n.js';
t('ui.accept')                         // '수락하고 공개'
t('ui.roundTitle', { n: 3 })           // '제 {n} 장' → '제 3 장'
t('log.gather', { who: 'player', place, res, n })   // 함수 값: 문법을 언어가 직접 처리
```

값은 세 가지 중 하나다.

| 값 | 언제 | 예 |
|---|---|---|
| 문자열 | 고정 문구, `{이름}` 자리 채우기 | `'제 {n} 장'` |
| 함수 `(v) => 문자열` | 조사·복수·어순·조건이 필요할 때 | `(v) => \`${josa(v.place, '을', '를')} 세웠다\`` |
| 배열 | 무작위(시드 고정) 대사 목록 | `['…', '…']` |

## 규칙

- **문장 단위로 키를 만든다.** 조각을 이어 붙이지 않는다 (언어마다 어순이 다르다). 조건에 따라 달라지는 문장은 함수 값 하나로 둔다.
- **키 이름**: `영역.무엇` — `ui.*`, `shell.*`, `log.*`, `data.<표>.<id>.<필드>`, `interp.*`, `kw.*`, `story.*`, `tut.*`.
- **데이터 표**(`data.js`)는 구조·숫자·id는 그대로 두고 글 필드만 `t()`로 바꾼다. 언어는 모듈을 읽을 때 정해지므로 표를 만들 때 한 번 불러도 된다.
- **표시 글을 코드가 다시 읽으면 안 된다.** 로그 문장을 정규식으로 다시 파싱하던 곳은 로그의 `fx` 같은 구조 정보로 바꾼다.
- **주석은 번역하지 않는다.** 개발 언어는 한국어다.
- 내부 id, CSS 클래스, 저장 키(`gsg.*`)는 글이 아니다.

## 번역이 아니라 "새로 써야" 하는 부분 — `kw.*`, `interp.*`

이 게임은 플레이어가 쓴 **자연어 계시**를 해석한다.

- `interp.*` — 대사제(LLM)에게 주는 프롬프트. 번역하되, 모델이 그 언어로 답하게 지시를 바꾼다.
- `kw.*` — 석판(키워드) 해석기와 말투·이름 붙이기·예언 탐지에 쓰는 **정규식 원본 문자열**이다. 한국어 어간(`세우`, `거두`…)을 그 언어의 어휘로 **새로 만들어야** 한다. 그대로 두면 그 언어로 쓴 계시를 알아듣지 못한다.

## 새 언어 더하기

1. `js/game/i18n/ko.js`와 `ko/` 폴더를 복사해 `en.js`, `en/`으로 만든다 (`grammar.js`는 그 언어에 맞게).
2. `js/game/i18n.js`의 `LOCALES`에 `en: 'English'`를 더한다.
3. 값을 번역한다. 키는 바꾸지 않는다.
4. `node tools/i18n-check.mjs --keys` 로 빠진 키를 확인한다. 빠진 키는 한국어로 나온다.
5. 설정에서 언어를 고르거나 `localStorage.setItem('gsg.lang', 'en')` 후 새로고침.
