# 언어팩 (i18n)

게임에 나오는 모든 글은 `js/game/i18n/` 아래 언어팩에 모여 있다. 코드에는 키만 남는다.

```
js/game/i18n.js          t(key, vars) · lang · LOCALES · setLang
js/game/i18n/ko.js       한국어팩 (기준). 아래 조각을 합친다
js/game/i18n/ko/
  grammar.js             한국어 조사 도우미 josa()
  ui.js                  화면: main.js · index.html
  shell.js               연출·보드·소리·그림: fx.js · board.js · sound.js · art.js
  engine.js              진행 기록(로그)·판정 문구: engine.js · mapgen.js · meta.js
  data.js                카드·사건·지도자·기적 등 데이터: data.js
  interp.js              해석기: 대사제 프롬프트, 석판(키워드) 사전, 말투 탐지: interpreter.js · lore.js
  story.js               연대기·에필로그·업적·튜토리얼: chronicle.js · tutorial.js
tools/i18n-check.mjs     코드에 남은 한글, 언어팩끼리 빠진 키를 찾는다
```

## 쓰는 법

```js
import { t } from './i18n.js';
t('ui.accept')                         // '수락하고 공개'
t('ui.roundTitle', { n: 3 })           // '제 {n} 장' → '제 3 장'
t('log.gather', { who: 'player', place, res, n })   // 함수 값: 문법을 언어가 직접 처리
```

값은 세 가지 중 하나다.

| 값 | 언제 | 예 |
|---|---|---|
| 문자열 | 고정 문구, `{이름}` 자리 채우기 | `'제 {n} 장'` |
| 함수 `(v) => 문자열` | 조사·복수·어순·조건이 필요할 때 | `(v) => \`${josa(v.place, '을', '를')} 세웠다\`` |
| 배열 | 무작위(시드 고정) 대사 목록 | `['…', '…']` |

## 규칙

- **문장 단위로 키를 만든다.** 조각을 이어 붙이지 않는다 (언어마다 어순이 다르다). 조건에 따라 달라지는 문장은 함수 값 하나로 둔다.
- **키 이름**: `영역.무엇` — `ui.*`, `shell.*`, `log.*`, `data.<표>.<id>.<필드>`, `interp.*`, `kw.*`, `story.*`, `tut.*`.
- **데이터 표**(`data.js`)는 구조·숫자·id는 그대로 두고 글 필드만 `t()`로 바꾼다. 언어는 모듈을 읽을 때 정해지므로 표를 만들 때 한 번 불러도 된다.
- **표시 글을 코드가 다시 읽으면 안 된다.** 로그 문장을 정규식으로 다시 파싱하던 곳은 로그의 `fx` 같은 구조 정보로 바꾼다.
- **주석은 번역하지 않는다.** 개발 언어는 한국어다.
- 내부 id, CSS 클래스, 저장 키(`gsg.*`)는 글이 아니다.

## 번역이 아니라 "새로 써야" 하는 부분 — `kw.*`, `interp.*`

이 게임은 플레이어가 쓴 **자연어 계시**를 해석한다.

- `interp.*` — 대사제(LLM)에게 주는 프롬프트. 번역하되, 모델이 그 언어로 답하게 지시를 바꾼다.
- `kw.*` — 석판(키워드) 해석기와 말투·이름 붙이기·예언 탐지에 쓰는 **정규식 원본 문자열**이다. 한국어 어간(`세우`, `거두`…)을 그 언어의 어휘로 **새로 만들어야** 한다. 그대로 두면 그 언어로 쓴 계시를 알아듣지 못한다.

### 그 언어로 새로 써야 하는 키 목록

| 키 | 무엇 |
|---|---|
| `kw.tablet.*`, `kw.negation`, `kw.clauseSplit`, `kw.lessonStop` | 석판 해석기의 동사·명사 어간, 부정, 절 나누기. 낱말 일부에 걸리지 않게 앞뒤 보기(`(?<!…)`, `(?!…)`)를 쓴다 — 그 언어의 오독 사례에 맞게 새로 짠다 |
| `kw.tablet.villageExcept`, `kw.tablet.templeExcept`, `kw.tablet.wallExcept` | 그 절이 마을·신전·성벽 규칙을 **쓰지 않게** 하는 말 ("적의 마을을 빼앗아라"는 마을 건설이 아니다, "안식일을 지켜라"는 성벽이 아니다) |
| `kw.tablet.gatherAny` | 무엇을 거둘지 말하지 않은 채집 ("자원을 모아라") — 가장 모자란 자원을 거둔다 |
| `kw.many` | 양의 말 ("모두", "많이") — 규칙 하나가 명령을 둘까지 만든다 |
| `kw.dontAnd`, `kw.dontAndNeg`, `kw.fear` | "~지 말고 ~하라"를 금지 절 + 명령 절로 나누는 패턴(`kw.dontAnd`, 캡처 1 = 동사; 코드는 `g` 플래그를 넘기지만 `interpreter.js`의 `kw`가 플래그를 무시해 첫 번째만 바뀐다 — [05](spec/05-interpreter.md)), 나눈 금지 절의 모양(**함수** `(v) => \`${v.verb}지 마라,\``), 금지가 아닌 동사(두려워·걱정… — "두려워하지 말고 쳐라") |
| `kw.nounSplit`, `kw.particle`, `kw.verbish`, `kw.stop`, `kw.citeStop` | 계시에서 명사를 뽑고 인용을 찾는 규칙 |
| `kw.miracle.*`, `kw.eternal`, `kw.tone.*`, `kw.naming*`, `kw.nameable`, `kw.prophecy.*` | 말한 기적, 영원한 계명, 말투, 이름 붙이기, 예언 |
| `kw.clean.*` | 대사제(LLM) 답에서 어색한 어미를 다듬는 규칙 |
| `kw.petition.*`, `kw.data.event.*.choice.*.tags`, `kw.data.commandment.*.re` | 청원·갈림길·계명에 계시로 답했는지 알아듣는 말 |
| `kw.data.sacred.*.word` | 오늘의 숨은 말 (화면에도 나온다) |
| `kw.ui.speech`, `kw.ui.preach` | 침묵 판정(글자 종류), 선교 제안 |
| `interp.systemPrompt`, `interp.prompt`, `data.priest.*.prompt`, `data.voice.*.prompt` | 대사제 프롬프트 — "그 언어로 답하라"로 바꾼다 |
| `ui.suggest.*`, `tut.*.suggest` | 예시 계시 — 그 언어의 `kw.*`로 해석되는 문장이어야 한다 |

`kw.liturgyStrip`은 성언이 없어진 뒤(`afab303`) 쓰이지 않는다 — 새 언어팩에는 없어도 된다.

석판이 무엇을 알아들었는지 보여 주는 `ui.heard.*`(`ui.heard.kind`는 행동 종류 → 이름 함수)와 `interp.tablet.cannot`(알아들었으나 지금 할 수 없는 일)은 번역하면 되지만, `ui.heard.none`의 예시 낱말은 그 언어의 `kw.tablet.*`에 걸리는 말로 고른다.

코드에 남은 언어 의존:
- `interpreter.js`의 `cleanSpeech`는 한글·라틴 문자만 남긴다 (`\p{Script=Hangul}`). 다른 문자 체계는 여기에 더한다.
- 메아리 판정(`engine.js` `isEcho`)은 공백과 문장부호(`\p{P}`)만 지우고 글을 비교한다. 대소문자가 있는 언어라면 이것만으로는 "Pray"와 "pray"가 다른 글이다.
- 목록 구분자 `', '`, `' / '`는 코드에 있다.
- 판 결과는 `state.winKind`(`doom`·`capital`·`cathedral`·`faith`·`convertAll`·`edict`·`extinct`·`bothExtinct`·`score`·`tutorial`)로 가른다. `winReason`은 표시용이다.

## 새 언어 더하기

1. `js/game/i18n/ko.js`와 `ko/` 폴더를 복사해 `en.js`, `en/`으로 만든다 (`grammar.js`는 그 언어에 맞게).
2. `js/game/i18n.js`의 `LOCALES`에 `en: 'English'`를 더한다.
3. 값을 번역한다. 키는 바꾸지 않는다.
4. `node tools/i18n-check.mjs --keys` 로 빠진 키를 확인한다. 빠진 키는 한국어로 나온다.
5. 설정에서 언어를 고르거나 `localStorage.setItem('gsg.lang', 'en')` 후 새로고침.
