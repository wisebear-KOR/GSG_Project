# 언어팩 (i18n)

게임에 나오는 모든 글은 `js/game/i18n/` 아래 언어팩에 모여 있다. 코드에는 키만 남는다.

```
js/game/i18n.js          t(key, vars) · lang · LOCALES · setLang
js/game/i18n/ko.js       한국어팩 (기준). 아래 조각을 합친다
js/game/i18n/ko/
  grammar.js             한국어 조사 도우미 josa()
  ui.js                  화면: main.js · index.html
  shell.js               연출·보드·소리·그림: fx.js · board.js · sound.js · art.js
  engine.js              진행 기록(로그)·판정 문구: engine.js · mapgen.js · meta.js
  data.js                카드·사건·지도자·기적 등 데이터: data.js
  interp.js              해석기: 대사제 프롬프트, 석판(키워드) 사전, 말투 탐지: interpreter.js · lore.js
                         (+ 까닭 코드 → 문장 도우미 cannotLabel과 닿지 않는 곳의 이름표 FAR_NAME, ui.js가 import)
  story.js               연대기·에필로그·업적·튜토리얼: chronicle.js · tutorial.js
tools/i18n-check.mjs     코드에 남은 한글, 언어팩끼리 빠진 키를 찾는다
```

## 쓰는 법

```js
import { t } from './i18n.js';
t('ui.accept')                         // '수락하고 공개'
t('ui.roundTitle', { n: 3 })           // '제 {n} 장' → '제 3 장'
t('log.gather', { who: 'player', place, res, n })   // 함수 값: 문법을 언어가 직접 처리
```

값은 세 가지 중 하나다.

| 값 | 언제 | 예 |
|---|---|---|
| 문자열 | 고정 문구, `{이름}` 자리 채우기 | `'제 {n} 장'` |
| 함수 `(v) => 문자열` | 조사·복수·어순·조건이 필요할 때 | `(v) => \`${josa(v.place, '을', '를')} 세웠다\`` |
| 배열 | 무작위(시드 고정) 대사 목록, 낱말 집합 | `['…', '…']` |
| 객체 | 낱말 → 값 표 (`t()`가 그대로 돌려준다) | `kw.nameable`, `kw.prophecy.numbers`, `87a0fce`의 `kw.place.terrainName`(`{ 산: 'mountain', … }`)·`kw.place.dir`(`{ 동: [0, 1], … }`) |

## 규칙

- **문장 단위로 키를 만든다.** 조각을 이어 붙이지 않는다 (언어마다 어순이 다르다). 조건에 따라 달라지는 문장은 함수 값 하나로 둔다.
- **키 이름**: `영역.무엇` — `ui.*`, `shell.*`, `log.*`, `data.<표>.<id>.<필드>`, `interp.*`, `kw.*`, `story.*`, `tut.*`.
- **데이터 표**(`data.js`)는 구조·숫자·id는 그대로 두고 글 필드만 `t()`로 바꾼다. 언어는 모듈을 읽을 때 정해지므로 표를 만들 때 한 번 불러도 된다.
- **표시 글을 코드가 다시 읽으면 안 된다.** 로그 문장을 정규식으로 다시 파싱하던 곳은 로그의 `fx` 같은 구조 정보로 바꾼다.
- **주석은 번역하지 않는다.** 개발 언어는 한국어다.
- 내부 id, CSS 클래스, 저장 키(`gsg.*`)는 글이 아니다.

## 번역이 아니라 "새로 써야" 하는 부분 — `kw.*`, `interp.*`

이 게임은 플레이어가 쓴 **자연어 계시**를 해석한다.

- `interp.*` — 대사제(LLM)에게 주는 프롬프트. 번역하되, 모델이 그 언어로 답하게 지시를 바꾼다.
- `kw.*` — 석판(키워드) 해석기와 말투·이름 붙이기·예언 탐지에 쓰는 **정규식 원본 문자열**이다. 한국어 어간(`세우`, `거두`…)을 그 언어의 어휘로 **새로 만들어야** 한다. 그대로 두면 그 언어로 쓴 계시를 알아듣지 못한다.

| `kw.miracle.*`, `kw.eternal`, `kw.tone.*`, `kw.naming*`, `kw.nameable`, `kw.prophecy.*` | 말한 기적, 영원한 계명, 말투, 이름 붙이기, 예언 |

석판이 무엇을 알아들었는지 보여 주는 `ui.heard.*`(`ui.heard.kind`는 행동 종류 → 이름 함수, `ui.heard.kindWord`는 금한 종류 → 이름, `ui.heard.also` "못 함: …", `ui.heard.forbid` "금함: …" — 뒤의 셋은 `78c891e`)와 `interp.tablet.cannot`·`ui.heard.cannot`·`ui.heard.also`(알아들었으나 하지 못한 일 — 까닭 코드 `preach`·`attack`·`wall`·`village`·`temple`·`explore`·`pray`·`gather`, `attack:law`·`attack:earth`·`village:law`·`temple:villages`, `<종류>:tile`(한 칸에 한 가지)·`<종류>:limit`(행동 수), `b470e03`의 `far:<칸 id>`(짚은 칸에서 못 한 일)와 `16492f4`의 `far:<곳 코드>`(닿지 않는 수도·성지 — `55d33dd`부터 언어와 무관한 코드 `capital.enemy`·`capital.player`·`holy`(`88878b6`부터 "노리는 곳"의 `aim`도)이고, 이름은 `ko/interp.js`의 표 `FAR_NAME`이 붙인다; `16492f4`~`c12a1e9`에는 키 `interp.place.capital`·`interp.place.holy`의 글이 그대로 코드에 들어갔다) — 둘 다 "E5(지금 그곳에서는 할 수 없다)"·"율법파 수도(지금 그곳에서는 할 수 없다)"로 바꾸는 **함수**), 그리고 금지만 알아들었을 때의 `interp.tablet.forbidOnly`(`16492f4` — 채집 종류 이름표 `FORBID_KIND`는 `ko/interp.js` 안 상수)는 번역하면 되지만, `ui.heard.none`의 예시 낱말은 그 언어의 `kw.tablet.*`에 걸리는 말로 고른다. 까닭 코드를 문장으로 바꾸는 일은 키가 아니라 `ko/interp.js`가 내보내는 도우미 `cannotLabel`이 하고 `ko/ui.js`가 그것을 import한다 — 새 언어팩도 `<언어>/interp.js`에 같은 이름의 도우미(와 그 안의 `FAR_NAME` — 없으면 코드 `capital.enemy`가 그대로 보인다)를 두고 `<언어>/ui.js`에서 불러 쓴다(`i18n-check`는 키만 보므로 빠져도 알려 주지 않는다). 칩 옮기기의 `ui.move.tip`·`ui.notice.pickMove`는 보통 번역이다.

코드에 남은 언어 의존:
- `interpreter.js`의 `cleanSpeech`는 한글·라틴 문자만 남긴다 (`\p{Script=Hangul}`). 다른 문자 체계는 여기에 더한다.
- ~~`interpreter.js`의 `splitDont`가 `kw.notBut`의 앞 낱말을 한국어 조사 정규식 `/에서가?$/`로 본다(`b470e03`)~~ — `16492f4`에서 언어팩 키 `kw.notButPlace`로 옮겼다. 이제 `node tools/i18n-check.mjs`의 "코드에 남은 한글"은 `i18n.js`의 언어 이름 한 줄뿐이다(`95eca5f`에서 확인, 한국어팩 1,344키).
- 메아리 판정(`engine.js` `isEcho`)은 공백과 문장부호(`\p{P}`)만 지우고 글을 비교한다. 대소문자가 있는 언어라면 이것만으로는 "Pray"와 "pray"가 다른 글이다. `9b43bbf`부터는 석판이 읽은 일의 종류 목록으로도 비교하므로(말만 바꾼 되풀이, `87a0fce`부터 두 장 전 계시까지), 그 언어의 `kw.tablet.*`가 부실하면 이쪽 판정도 약해진다.
- 목록 구분자 `', '`, `' / '`는 코드에 있다.
- 판 결과는 `state.winKind`(`doom`·`capital`·`cathedral`·`faith`·`convertAll`·`edict`·`extinct`·`bothExtinct`·`score`·`tutorial`)로 가른다. `winReason`은 표시용이다.

## 새 언어 더하기

1. `js/game/i18n/ko.js`와 `ko/` 폴더를 복사해 `en.js`, `en/`으로 만든다 (`grammar.js`는 그 언어에 맞게).
2. `js/game/i18n.js`의 `LOCALES`에 `en: 'English'`를 더한다.
3. 값을 번역한다. 키는 바꾸지 않는다.
4. `node tools/i18n-check.mjs --keys` 로 빠진 키를 확인한다. 빠진 키는 한국어로 나온다.
5. 설정에서 언어를 고르거나 `localStorage.setItem('gsg.lang', 'en')` 후 새로고침.
