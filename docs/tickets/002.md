# #002 금지어 율법 (검열 카드)

- 관점: 서사
- 규모: S · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
적이 "다음 장 '불'이라는 말을 금한다"고 선포한다. 자유 텍스트 입력이라는 고유 인터페이스를 겨냥한 기믹이라 은유와 우회 표현의 재미가 생긴다.

## 구현 메모
율법 카드 L10 검열: 플레이어 최근 계시의 잦은 명사를 봉인(state.bannedWords). 입력 시 금지어가 붉게 번지고, 쓰면 비용 +2. LLM에는 금지어 전달.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **단순화**

L10 검열은 보통·어려움 덱에 1장. 금지어 1개(2글자 이상 명사), 1장 유지, 쓰면 계시 비용 +1(티켓의 +2는 과함). 행동이 비지 않도록 채집 규칙 2개를 붙인다. 첫 판(기록 0판)에는 나오지 않는다. 두루마리 머리에 봉인 칩, 입력 중 붉은 밑줄.
