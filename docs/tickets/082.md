# #082 한 해의 달력과 축제

- 관점: 서사
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
12장이 1년이 되어 계절 리듬과 축제 장이 기승전결을 만든다.

## 구현 메모
장→계절 매핑과 사건 가중치. 축제(하지제: 계시 비용 0·교리 +2, 추수제, 동지: 시야 개방). 계절 테두리와 BGM 음색.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화 — 연출만**

장 번호 옆 달 이름, 막 전환 제목 카드. 축제의 규칙 효과는 폐기(막·계절·갈림길이 이미 변주를 만든다).
