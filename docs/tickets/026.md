# #026 경전 편찬과 정경 봉헌

- 관점: 서사
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
판이 끝나면 계시가 한 권의 경전이 되고, 한 구절을 정경으로 봉헌하면 다음 판에 이어진다.

## 구현 메모
종료 시 계시+결과 주석을 책 페이지로. 한 구절을 gsg.canon(최대 3)에 봉헌 → 다음 판 해당 교리 +1, 프롬프트 "이 부족의 경전".

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **단순화**

정경 최대 3개 저장, 판마다 적용은 1개(해당 교리 +1, 3 미만 원칙과 무관한 시작 보정). 일일 판·어려움은 수치 효과 끄고 프롬프트만. 첫 종료 때는 탭만, 봉헌은 두 번째 판부터.
