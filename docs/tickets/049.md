# #049 행동 칩 토글 (부분 거부)

- 관점: 손맛
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
하나가 마음에 안 들어도 통째로 다시 굴려야 한다. 칩을 눌러 "알아서"로 돌리면 통제감이 생긴다.

## 구현 메모
확인 창 .order 클릭 → accepted에서 빼고 autoFill 재계산, 칩 뒤집힘 연출.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현**

확인 칩 클릭 → 그 행동을 빼고 validate/autoFill 재계산(무료, 장당 2개까지), 다시 누르면 복원. 청원·연결·서원·승률 파생값을 한 함수(derivePending)로 재계산. 날아오는 중엔 비활성.
