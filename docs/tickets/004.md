# #004 말투의 공명 (문체가 효과가 된다)

- 관점: 언어
- 규모: S · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
같은 명령도 명령·비유·예언·축복·저주로 말하느냐에 따라 결과가 달라져 문장을 다듬는 것 자체가 전략이 된다.

## 구현 메모
말투 판정(정규식 공통, LLM은 tone enum 선택): 축복 → 채집 +1, 저주 → 공격 +1·신앙 -1, 비유 → 교리 +1 추가, 예언 → 다음 장 신앙 +1. 인장 옆 말투 문장.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **단순화 — 은총 한도에 포함**

말투 하나만: 축복(첫 채집 +1) / 저주(이번 장 공격 +1, 신앙 -1) / 비유(교리 +1, 해당 교리 3 미만일 때만). 예언 말투는 #016으로 옮긴다. 판정은 정규식(두 모드 공통). 발동했을 때만 확인 창에 태그 하나.
