# #099 말을 거두기 (확인 전 되돌리기)

- 관점: 손맛
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 완료

## 왜 재미/중독성
인장을 찍은 뒤 오타나 뜻밖의 해석이면 좌절한다. 장당 한 번 원문을 고쳐 다시 쓸 수 있게.

## 구현 메모
확인 창 "말을 거두기"(Esc): phase=speak, draft=원문, 신앙 환불 규칙. 장당 1회.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — #092 병합 「되묻기」**

확인 화면 「말을 거두기 Esc」: 초안을 되살려 말하기로. 다시 해석과 장당 1회 슬롯 공유, 순비용 신앙 1(첫 판은 전액 환불).

## 구현 기록
되묻기: 계시 직전 판을 저장해 두고, 확인 화면 '말을 거두기 Esc'로 원문을 되살려 말하기로(다시 해석과 장당 1회 공유, 순비용 신앙 1, 첫 판은 무료). 다시 해석하면 이전 해석을 남겨 '↔ 이전 해석과 바꾸기'로 고를 수 있다(스키마 변경 없음).
