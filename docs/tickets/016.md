# #016 예언 계약 (기한 있는 예언)

- 관점: 언어
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
"세 장 안에 적의 성벽이 무너지리라"가 이뤄지면 크게 보상받고 경전에 금박으로 남는다. 말로 미래에 거는 도박.

## 구현 메모
예언 유형 enum(적 마을 함락, 수도 피해, 인구 도달, 풍년, 개종) + 기한 1~3장. 석판은 "~하리라" 절과 숫자 추출. 성취 시 신앙 +기한×2, 실패 시 -2. 보드 가장자리 봉인 두루마리.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **단순화 — 명시적 봉인만**

"~하리라"는 기본 문체라 자동으로 걸지 않는다. 예언형 문장이 잡히면 확인 창 체크박스 "예언으로 봉인". 동시에 1개, 끝난 다음 장부터 재계약. 1장 +4 / 2장 +3 / 3장 +2, 실패 -2. 유형: 적 마을 함락·수도 피해·인구·개종.

## 구현 기록
lore.parseProphecy(유형이 잡히는 예언형 문장만). 확인 창 체크박스로만 봉인, 동시에 1개. 1장 +4 / 2장 +3 / 3장 +2, 실패 -2. 유지 단계에서 판정, 두루마리 위 '봉인된 예언' 표시.
