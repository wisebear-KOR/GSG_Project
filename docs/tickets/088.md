# #088 볼륨 슬라이더와 오디오 덕킹

- 관점: 손맛
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 완료

## 왜 재미/중독성
핵심 순간에 BGM이 겹쳐 임팩트가 묻힌다. 덕킹하면 같은 소리도 두 배로 느껴진다.

## 구현 메모
bus.music duck() 헬퍼를 인장·충격·승리에 호출. 음악·효과음 range 팝오버, localStorage.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — 설정 화면**

음악·효과음 슬라이더(gsg.vol.*), 기존 토글은 음소거. 인장·충격·승리 때 음악 덕킹.

## 구현 기록
sound.js: 음악·효과음 볼륨(gsg.vol.*, 스위치는 음소거로 남김), 음악 버스 뒤 duck 게인 — 인장·충격·번개·승패·성가·타격 때 음악을 잠깐 낮춘다. 설정 화면 슬라이더.
