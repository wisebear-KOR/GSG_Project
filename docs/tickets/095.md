# #095 승천 단계 (어려움+)

- 관점: 리텐션
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 완료

## 왜 재미/중독성
어려움을 이긴 뒤에도 갈 곳이 있어야 오래 한다.

## 구현 메모
hard 위 ascension 1~10, 단계마다 제약 하나씩. gsg.meta.ascension, diffHint에 제약 목록.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화 — 1~5단계**

어려움 승리로 열림. 누적: 율법파 시작 신도 +1 / 석판 한계 -2 / 분노 문턱 6→8 / 3막 율법파 행동 +1 / 은사 없음. diffHint와 기록에 표시.

## 구현 기록
어려움 승리로 한 단계씩 열림(gsg.ascension, 최대 5). 누적: 율법파 시작 신도 +1 / 석판 한계 -2 / 분노 격차 8 / 3막 율법파 행동 +1 / 은사 없음. 어려움 선택 시 승천 선택, diffHint에 제약 목록, 기록 키와 요약에 승천·규칙 판(RULESET 4).
