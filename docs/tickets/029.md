# #029 입력 중 닿을 행동 미리 빛남

- 관점: 손맛
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
계시를 치는 동안 보드가 은은하게 반응하면 LLM 호출 전부터 신의 손맛을 느낀다.

## 구현 메모
입력 디바운스 250ms, 석판 해석기로 매칭된 행동의 칸에 hint-glow. 키워드가 맞을 때 작은 틱.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현**

250ms 디바운스, 석판 해석으로 최대 6칸을 흐리게 "예감" 표시. LLM 모드에선 약속이 아니라 예감이라는 툴팁.

## 구현 기록
250ms 디바운스로 석판 해석 → board hints(hint-ring, 점선 금빛 펄스), 새 칸이 생기면 hover 틱.
