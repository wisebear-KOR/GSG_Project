# #090 과로 (행동 상한 초과)

- 관점: 시스템
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 폐기

## 왜 재미/중독성
후반엔 행동 6에 막혀 성장이 평평하다. 식량을 내고 추가 행동을 사면 후반에도 자원 고민이 이어진다.

## 구현 메모
MAX_ACTIONS 초과 신도는 식량 2로 추가 행동, 1/3 확률로 다음 장 행동 -1. 금색 추가 슬롯.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **폐기**

버튼과 확률만 늘고 결정은 늘지 않는다. 후반의 평평함은 심판 기준·대성당·석판이 맡는다.
