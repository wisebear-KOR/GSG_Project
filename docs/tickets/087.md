# #087 안개 속 적 행동의 방향 암시

- 관점: 손맛
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
"보이지 않는다"는 정보 가치가 0이다. 방향만 알려 줘도 탐험 이유와 긴장이 생긴다.

## 구현 메모
숨겨진 적 행동 배너에 방위(북동 등), 안개 칸 붉은 링, 스테레오 패닝 발소리.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화**

안개 속 율법파 배너에 우리 수도 기준 8방위(「북동쪽 안개 속의 움직임」). 좌우 패닝 발소리. 붉은 링은 정확한 칸을 드러내므로 폐기.
