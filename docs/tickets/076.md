# #076 적 교단 4종

- 관점: 서사
- 규모: L · 우선도: 4 · 웨이브: 3차 — 우선도 4, 중간 이상
- 상태: 대기

## 왜 재미/중독성
적이 예측 가능하다는 약점을 정면으로 푼다. 교단마다 덱·특기·색이 달라 판의 결이 바뀐다.

## 구현 메모
FACTIONS: 율법파 / 불의 교단(숲을 태움) / 무신 상인 연맹(식량으로 신도 매수, 선교 면역) / 망자의 교회(쓰러진 자가 적으로 일어남). 오토마 규칙 타입 확장(burn, bribe, raise).
