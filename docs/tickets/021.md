# #021 판 이어하기 (자동 저장)

- 관점: 리텐션
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
20~40분 판이 탭을 닫으면 사라진다. 저장이 있으면 "3장만 더"로 끊어서 다시 들어오기 쉽다.

## 구현 메모
newRound/재생 끝에 state를 localStorage gsg.save.v1에 저장(tileAt 제외, 로그 snap 제거). 로드 시 복원, 메인 화면 "이어하기". 종료 시 삭제.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현**

serializeState/hydrateState: 로그 스냅숏 제거, 카드는 id로, tileAt 재구성, 버전 불일치면 폐기. 저장 시점: 장 시작, 재생 끝, 기적 사용 직후. 판 종료 시 삭제.

## 구현 기록
engine.serializeState/hydrateState, meta.js(gsg.save.v1). 장 시작·해결 끝·기적 직후 저장, 판이 끝나면 삭제. 메인 화면 이어하기 버튼. 결정론 검사(det.mjs): 저장·복원 후 결과 동일.
