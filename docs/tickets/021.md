# #021 판 이어하기 (자동 저장)

- 관점: 리텐션
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
20~40분 판이 탭을 닫으면 사라진다. 저장이 있으면 "3장만 더"로 끊어서 다시 들어오기 쉽다.

## 구현 메모
newRound/재생 끝에 state를 localStorage gsg.save.v1에 저장(tileAt 제외, 로그 snap 제거). 로드 시 복원, 메인 화면 "이어하기". 종료 시 삭제.
