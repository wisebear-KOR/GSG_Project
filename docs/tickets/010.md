# #010 전역 단축키

- 관점: 손맛
- 규모: S · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
매 장 마우스 클릭으로 리듬이 끊긴다. 숙련자 템포를 올린다.

## 구현 메모
confirm: Enter 수락, R 다시 해석 / 재생: Space 빨리 감기 / resolved: Enter 다음 장 / speak: 1~3 기적, L 연대기. 버튼에 kbd 배지.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현**

confirm: Enter 수락(300ms 연타 방지), R 다시 해석 / playing: Space 빨리 감기 / resolved: Enter·Space 다음 장 / speak: Alt+1~3 기적. 입력란 포커스 중에는 Ctrl+Enter 외 무시. 버튼에 kbd 배지.

## 구현 기록
onKey: confirm Enter(300ms 잠금)/R, 재생 Space, 결산 Enter·Space, Alt+1~3 기적, L 연대기. 입력 중엔 무시. 버튼 kbd 배지.
