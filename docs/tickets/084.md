# #084 복귀 인사와 기록 내보내기

- 관점: 리텐션
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
며칠 만에 돌아온 플레이어에게 벌 대신 맥락을 준다. 기기 이동도 가능.

## 구현 메모
gsg.lastVisit 3일 이상 → 메인에 지난 판 요약. gsg.* 전체 JSON 내보내기/가져오기.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — 설정 화면에 포함**

마지막 방문이 3일 이상이면 메인에 지난 판 카드. 설정 화면 「기록 내보내기 / 가져오기」(gsg.* 검사, 덮어쓰기 확인).
