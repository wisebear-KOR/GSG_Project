# #013 교리 궁극 특전 (6칸)

- 관점: 시스템
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
교리 5~6칸이 의미 없다. 끝을 규칙 파괴로 채우면 한 교리에 몰아주는 빌드 판단과 "한 장만 더"가 생긴다.

## 구현 메모
평화6: 장 끝 인접 적 칸 자동 선교 / 전쟁6: 공격에 져도 신도를 잃지 않음 / 풍요6: 인구 상한 +3 / 지혜6: 다음 사건 2장 중 선택.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **단순화**

평화6: 장 끝 인접 적 마을 자동 선교 1회(표식 없음) / 전쟁6: 공격에 져도 신도 유지 / 풍요6: 인구 상한 +2 / 지혜6: 다음 사건 2장 중 선택. 가속원(비유·이름·정경)은 교리 3 미만에서만 동작해 궁극은 빨라도 8장 이후.

## 구현 기록
평화: 장 끝 인접 적 마을 자동 선교(방어 +1, 표식 없음) / 전쟁: 공격에 지면 신도 대신 신앙 2 / 풍요: 인구 한도 +2 / 지혜: 계절 두 장 중 선택(계절 카드 버튼). 시뮬레이션 결과 한 교리 몰빵이 과해 궁극은 8장부터 깨어나도록 제한(ULT_ROUND). 6번째 보석 금테.
