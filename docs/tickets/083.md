# #083 사건·율법 도감

- 관점: 리텐션
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 완료

## 왜 재미/중독성
드문 사건을 처음 볼 때 기록되면 판마다 작은 발견이 생긴다.

## 구현 메모
gsg.seen {events, laws}. 서고 카드 격자, 미발견은 실루엣. 첫 등장 시 "새 기록" 표식.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — #096과 병합 「서고 · 도감」**

gsg.seen에 계절·갈림길·율법·발견지·지도자·기적·계명을 기록, 못 본 것은 실루엣. 서고 안의 탭.

## 구현 기록
meta.markSeen(gsg.seen): 계절·갈림길·미라·율법·지도자·발견지·기적·계명. meta.noteWords(gsg.lexicon): 행동 종류·말투마다 처음 이끈 문구(20자)와 횟수. 서고 머리 '도감 · 어휘집' 접이식, 못 본 것은 '?'.
