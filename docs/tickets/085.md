# #085 신앙 위기 경보 (비네트와 심장박동)

- 관점: 손맛
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
이단 경고가 텍스트 한 줄이라 놓치기 쉽다. 긴장과 기도 동기를 분명히.

## 구현 메모
body.faith-crisis 붉은 비네트 펄스, 저음 박동 레이어.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화**

faithless ≥ 1(위기)일 때만 body.faith-crisis: 기존 비네트를 붉게, 들어설 때 심장 박동 두 번. 모션 줄이기를 따른다.
