# #032 교리 대립 (반대 교리는 깎인다)

- 관점: 시스템
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
네 트랙이 오르기만 하면 섞어 말하는 게 공짜다. 평화-전쟁, 풍요-지혜를 대립시키면 한마디에 정체성의 비용이 붙는다.

## 구현 메모
recordRevelation에서 반대 트랙 -1(특전 경계에서는 경고). 교리 패널에 대립 선 표시. 연대기 "평화의 서약이 흔들린다".

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **단순화 — 두 번째 판부터**

평화↔전쟁, 풍요↔지혜. 한쪽이 오르면 반대 -1, 단 이미 얻은 특전 칸(2/4/6) 아래로는 깎지 않는다(특전을 잃지 않음). 석판이 아무 행동도 못 찾은 계시는 교리로 치지 않는다. 연대기 "○○의 서약이 흔들린다", 교리 패널 대립 표시.
