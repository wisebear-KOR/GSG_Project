# #048 주사위 승률 표시와 긴장 빌드업

- 관점: 손맛
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 완료

## 왜 재미/중독성
굴리기 전 확률이 보이면 결과의 기쁨과 아픔이 커진다. 역전 승리는 "기적!".

## 구현 메모
rollDice에 odds 인자(d6 대 d6 + 보너스 승률), 승률 막대, 드럼롤. 30% 미만 승리 시 추가 연출.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현**

36가지 경우로 정확한 승률(동점은 패). 확인 칩 끝에 "42%", 주사위 창 승률 막대와 드럼롤. 30% 미만 승리면 "기적!". 방언·불기둥·저주·우위 보너스 반영.

## 구현 기록
engine.actionOdds(36가지 정확 계산, 교리·우위·방언·불기둥·저주 반영) → 확인 칩 '42%'(초록/빨강), 주사위 창 라벨에 승률, 30% 미만으로 이기면 '기적!' 빛과 소리.
