# #020 신격 선택 (비대칭 판테온)

- 관점: 서사
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
어떤 신이 되느냐가 말하는 방식의 제약이자 힘이 된다. 반복 플레이와 롤플레이 동기.

## 구현 메모
GODS: 폭풍의 주(번개 -2, 단비 불가) / 침묵의 신(12자 제한, 짧을수록 환급) / 대지모(성장 +, 공격 불가) / 거짓말쟁이 신(율법 미리 봄, 1/4 반대 해석). 설정 화면 선택.
