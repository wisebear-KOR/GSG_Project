# #035 심판의 기준 카드 (판마다 다른 승점 공식)

- 관점: 시스템
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 완료

## 왜 재미/중독성
승점 공식이 고정이면 최적 빌드가 고정된다. 판마다 기준이 바뀌면 같은 맵도 다른 전략.

## 구현 메모
JUDGEMENTS 6장(넓은 자: 마을×5 / 경건한 자: 신앙·신전 / 용맹한 자: 점령×4 등). score가 가중치를 따른다. 판 시작 공개.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현 — 두 번째 판부터**

JUDGEMENTS(기본·넓은 자·번성한 자·경건한 자·굳센 자), 가중치 합을 기본과 비슷하게 맞춤. 시드 해시로 선택, 첫 판은 기본. score()가 scoreBreakdown 합계 → 기록·결산·요약·그래프가 모두 자동으로 따른다. 판 시작 장 제목과 트랙에 카드 이름, 서고 기록에 id.

## 구현 기록
JUDGEMENTS 5장(기본·넓은 자·번성한 자·경건한 자·굳센 자), 두 번째 판부터 시드 해시. score()가 scoreBreakdown 합계라 기록·결산·그래프·요약·업적이 모두 따른다. 1장 제목·부제에 표시.
