# #100 접근성 (색각 패턴·스크린리더)

- 관점: 손맛
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 완료

## 왜 재미/중독성
파랑/빨강 위주 구분과 role=img 보드는 일부 플레이어를 배제한다.

## 구현 메모
진영별 SVG 패턴 옵션, aria-live 해설, 칩 aria-label.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — 설정 화면**

진영 무늬(우리 사선, 율법파 점), 배너·결산 aria-live, 칩·칸 aria-label, focus-visible, 글자 크기 3단계.

## 구현 기록
설정 화면: 진영 무늬(우리 사선·율법파 점, 율법파 테두리 점선), 글자 크기 3단계(zoom). #sr aria-live: 장 시작, 해결 배너, 장 결산을 읽는다. 보드 aria-label에 장·땅·승점, focus-visible 링, 설정 칩 aria-label.
