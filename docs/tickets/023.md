# #023 성서 (업적)

- 관점: 리텐션
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
"아직 안 해 본 방식으로 이기기"가 흐름이 비슷하다는 약점을 줄인다.

## 구현 메모
ACHIEVEMENTS 약 25개 {id, name, desc, check}. 판 종료·장마다 검사, gsg.ach. 해금 배너 "새 구절이 성서에 기록되었다". 미해금은 흐리게.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현 — 게임 내 보상 없음**

약 20개, 누적형(번개 20회 등) 대신 방식형(기적 없이 승리, 평화로만 승리). 해금 배너는 재생이 끝난 뒤. 메인 "성서" 목록, 미해금은 흐리게.

## 구현 기록
chronicle.ACHIEVEMENTS 20개(방식형 위주), 판 종료 시 평가 → meta.unlockAchievements, 종료 양피지에 새 구절 표시, 메인 '성서 · n/20' 칩(미해금은 흐리게). 튜토리얼 완료도 구절.
