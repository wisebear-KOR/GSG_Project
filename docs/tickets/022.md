# #022 연대기 서고 (판 기록)

- 관점: 리텐션
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
지난 판의 계시와 결과가 쌓이면 "내 신의 역사"가 되어 소유감이 생긴다. 다른 메타 기능의 토대.

## 구현 메모
판 종료 시 gsg.history(최근 50판)에 요약 저장. 메인 화면 서고 탭, 행 클릭 시 계시 전문 두루마리.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현**

판 요약 스키마를 먼저 확정: 날짜, 시드, 크기, 난이도, 지도자, 승패·유형, 승점, 장 수, 교리, 계시 목록, 칭호. 최근 50판. 메인 화면 "서고".
