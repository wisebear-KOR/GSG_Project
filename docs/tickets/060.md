# #060 말한 대로 내리는 기적

- 관점: 언어
- 규모: M · 우선도: 4 · 웨이브: 3차 — 우선도 4, 중간 이상
- 상태: 완료

## 왜 재미/중독성
카드 클릭 대신 "하늘이여, 저 마을에 불을 내려라"라고 쓰면 번개가 떨어진다. 기적이 주문이 된다.

## 구현 메모
스키마 miracle {kind, target}. 비용·잔여 조건이 맞을 때만 발동, 확인 창에 "기적이 감지됨". 석판: 번개|벼락|불을 내려 → 번개, 비|단비 → 단비.

## 검토와 결정
3차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현**

lore.parseMiracle: 번개|벼락|불을 내려 → 번개, 비|단비 → 단비, 만나 등. 손에 있고 비용이 되고 이번 장 기적을 안 썼을 때만. 대상: 이름 붙인 칸 → 연결 칸 → 가장 가까운 보이는 적 마을. 확인 칩 「⚡ 번개 — 신앙 4」(뺄 수 있음), 수락 때 발동. 심판의 날은 말로 부를 수 없다.

## 구현 기록
lore.parseMiracle(손에 든 기적만): 번개·벼락/단비/만나/방주/방언/불기둥/부활 등. 이번 장 미사용·신앙 충분할 때 확인 칩 '기적 · 신앙 N'(번개는 이름 붙인 적 칸 → 가장 가까운 보이는 적 마을), 칩으로 뺄 수 있음, 수락 때 castMiracle. 심판의 날은 말로 부를 수 없음.
