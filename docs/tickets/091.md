# #091 잊힌 신과의 계약

- 관점: 서사
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 폐기

## 왜 재미/중독성
궁지에서 옛 신이 거래를 제안한다. 달콤한 힘과 미뤄진 대가가 역전 드라마를 만든다.

## 구현 메모
PACTS(굶주린 달: 번개 3회 무료, 4장 뒤 인구 절반 이탈 등). 인구가 크게 뒤처지거나 신앙 0일 때 제안. state.debts 추심. 검은 양피지 모달.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **폐기**

신의 분노→심판의 날이 이미 역전 장치다. 둘이 되면 뒤처지는 쪽이 유리해진다.
