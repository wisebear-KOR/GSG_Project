# 2차 웨이브 검토 요약

두 관점의 서브 에이전트(밸런스·플레이어 경험, 기술 설계)가 #030~#051을 검토했다. 티켓별 결론은 각 티켓의 "검토와 결정"에 있다.

## 원칙
- **의도는 진실이어야 한다.** 율법 카드를 고르는 일(#031, #036)은 장 시작에 직전 장의 계시로 확정한다. 말하기 중에 이번 계시로 카드를 바꾸지 않는다.
- **은총 한도 +1 유지.** 서원(#036)·기이한 해석(#039)은 은총 풀 안에서, 인용(#040)은 신앙 대신 계시 비용 할인으로.
- **말하기 단계에 새로 보이는 것은 둘뿐:** 다음 계절 카드(#038), 제안 칩(#051, 8초 뒤·첫 3판).
- **첫 판 보호에 추가:** 교리 대립(#032), 심판의 기준(#035).
- **점수 공식은 score() 하나로.** 심판 기준은 scoreBreakdown으로 넣어 기록·결산·요약·그래프가 자동으로 따른다.
- **저장 형식은 그대로(SAVE_VERSION 1),** 새 필드는 hydrate 기본값으로.
- **보류:** #042 숨은 성언(3차 #063과 함께), #030의 짧은 계시 선공 보상.

## 구현 묶음
- A 점수와 규칙 가시성: #035 심판 기준, #034 승점 분해·역전 힌트, #033 신의 분노, #038 다음 사건, #030 선공
- B 교리 경제와 적의 반응: #032 대립, #037 연속, #031 적의 반응, #036 서원, #050 특전 연출
- C 제단의 말: #049 칩 토글, #039 기이한 해석, #040 인용, #041 사제의 말투, #051 제안 칩
- D 메타와 손맛: #043 이력, #046 최고 기록, #045 도전 링크 + #044 시편 복사, #047 콤보 음계, #048 주사위 승률
