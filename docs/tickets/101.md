# #101 모바일 터치 (탭 툴팁·하단 시트)

- 관점: 손맛
- 규모: L · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
폰에서 한 손으로 할 수 있어야 짧은 세션 중독성이 생긴다.

## 구현 메모
롱프레스 툴팁, 720px 이하 제단 하단 시트, 매트 요약 바, 햅틱.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화 — 최소 모바일**

Prompt API는 데스크톱 전용이라 모바일은 석판 모드. 롱프레스 칸 설명과 390px 가로 스크롤 없음까지. 하단 시트·햅틱은 보류.
