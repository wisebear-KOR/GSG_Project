# #051 계시 제안 칩 (빈 두루마리 공포 해소)

- 관점: 손맛
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
무엇을 말할지 막히는 것이 자유 텍스트 게임의 가장 큰 마찰이다.

## 구현 메모
상황 규칙 기반 제안 2~3개(신앙 부족 → 기도, 적 인접 → 성벽, 식량 부족 → 강). 클릭 시 타자 효과로 채움. 끌 수 있음.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **단순화**

입력이 비고 8초 지나면 칩 2개(청원 필요·적 의도·신앙 부족 기반, 봉인된 말 제외). 첫 3판만 기본 켜짐, 끌 수 있음, 입력 시작하면 사라짐. 누르면 타자 효과로 채움.
