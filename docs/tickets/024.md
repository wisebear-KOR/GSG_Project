# #024 사관 세라의 과제 (튜토리얼 이후)

- 관점: 리텐션
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
튜토리얼 직후가 가장 많이 이탈한다. 다음 두세 판에 작은 목표를 이어 첫 승리까지 안내.

## 구현 메모
gsg.onboard 단계별 과제(마을 짓기 → 기적 쓰기 → 교리 특전 → 보통 승리). 세라 말풍선 재사용, 끌 수 있음.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현**

과제 4개(마을 하나 → 기적 한 번 → 교리 특전 → 쉬움 승리). 세라 말풍선 재사용, 매트 머리 리본 하나, 끌 수 있음. 판정 코드는 #023과 공유.

## 구현 기록
과제 4개(마을 → 기적 → 교리 2칸 → 승리), 우리 매트 머리 리본(끌 수 있음), 달성 시 세라 말풍선과 다음 과제. gsg.onboard.
