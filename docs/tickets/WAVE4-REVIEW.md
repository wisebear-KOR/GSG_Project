# 4차 웨이브 검토 요약

두 관점의 서브 에이전트(밸런스·플레이어 경험·서사, 기술 설계)가 #078~#101과 보류했던 #020·#066·#074·#076·#077을 검토했다. 목표는 기능을 더하는 것이 아니라 완성된 "진짜 게임"으로 다듬는 것이다.

## 폐기
#079 신의 피로, #090 과로, #091 잊힌 신과의 계약, #066 성유물, #076 적 교단(1.0).
부분 폐기: #082 축제 규칙, #087 붉은 링, #074 위협·수확량 레이어, #101 하단 시트·햅틱, #077 이어지는 캠페인.

## 병합
- #092 + #099 → 되묻기
- #089 + #093 → 분열의 예언자 (갈림길)
- #083 + #096 → 서고 · 도감
- #094 + #077 + #097 + #020 → 시련 5개 + 이번 주의 시련
- #098 + #074 → 국경선
- #088 + #100 + #084 → 설정 화면

## 구현 묶음
- A 설정과 기반: 설정 화면(볼륨·덕킹, 무늬·글자·aria, 내보내기·복귀 인사), #086
- B 보드 손맛: #098 국경선, #087 방위, #085 위기 비네트, #101 최소 모바일
- C 말의 무게: 되묻기, #080 침묵, #081 전설의 땅
- D 서사 긴장: 분열의 예언자, #078 피의 율법, #082 달 이름
- E 메타와 모드: 도감, 시련, #095 승천

## 완성도 체크리스트 (티켓 밖)
설정 화면, 일시정지 메뉴, 게임 안 규칙서와 용어집, 새로 열린 요소 안내, LLM 다운로드 안내, 밸런스 자동 대전, 정보 밀도 감사, 오디오 믹스, 성능(숨은 탭에서 멈춤), 저장 안정성, 결정론 회귀 테스트, 용어 통일, 크레딧과 버전.
