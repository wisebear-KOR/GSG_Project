# #011 율법파 의도 예고 (칸 단위 텔레그래프)

- 관점: 시스템
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
적이 무엇을 어디에 할지 계시 전에 보이면 매 장이 "막을까 피할까 맞받아칠까"를 푸는 퍼즐이 되고, 계시로 위협을 뒤집을 때 내 말이 세상을 바꿨다는 감각이 가장 크다.

## 구현 메모
startRound 끝에 planEnemy를 미리 계산해 state.enemyIntent에 보관하고 resolveRound에서 재사용(무효해진 행동만 재선정). board.js에 의도 마커(칼/두루마리/망치), LLM 프롬프트에 "율법파가 D3를 노린다" 줄.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현 — 난이도별 공개량**

장 시작에 적 계획을 확정해 그대로 실행(기적 뒤에만 재계획). 쉬움: 전부 / 보통: 공격·교화·건설만 / 어려움: 공격만. 보드 마커 + 율법 카드 뒷면 요약 + 프롬프트 한 줄. 세라가 1장에 소개.

## 구현 기록
engine.enemyIntent(state): planEnemy는 난수를 쓰지 않아 예고 = 실제 행동. 난이도별 공개(쉬움 전부/보통 공격·교화·건설/어려움 공격), 안개 속은 숨김. 보드 붉은 점선 테와 아이콘 배지, 율법 카드 뒷면 '율법파의 뜻' 목록, 칸 툴팁, LLM 프롬프트 '율법파의 의도' 줄.
