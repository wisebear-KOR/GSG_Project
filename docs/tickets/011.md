# #011 율법파 의도 예고 (칸 단위 텔레그래프)

- 관점: 시스템
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
적이 무엇을 어디에 할지 계시 전에 보이면 매 장이 "막을까 피할까 맞받아칠까"를 푸는 퍼즐이 되고, 계시로 위협을 뒤집을 때 내 말이 세상을 바꿨다는 감각이 가장 크다.

## 구현 메모
startRound 끝에 planEnemy를 미리 계산해 state.enemyIntent에 보관하고 resolveRound에서 재사용(무효해진 행동만 재선정). board.js에 의도 마커(칼/두루마리/망치), LLM 프롬프트에 "율법파가 D3를 노린다" 줄.
