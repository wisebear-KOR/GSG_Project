# #094 규칙 비틀기 시나리오 모음

- 관점: 서사
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 완료

## 왜 재미/중독성
대홍수, 유배된 신, 두 섬, 성지 쟁탈전 같은 변주가 익숙한 판을 새롭게 만든다.

## 구현 메모
SCENARIOS + modifiers 훅(roundStart/roundEnd/onGather). 메인 화면 시나리오 목록.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화 — 「시련」 (#077·#097·#020 흡수)**

시련 5개(폭풍의 주, 대지모, 칼의 해, 침묵의 수도원, 마지막 예언자): 고정 시드 + 수정자 하나 + 도입/맺음 글, 별 3개 평가. 「이번 주의 시련」(ISO 주 해시). 이어지는 캠페인 보상은 보류.

## 구현 기록
TRIALS 5종(폭풍의 주·대지모·칼의 해·침묵의 수도원·마지막 예언자): 고정 시드 + 비틀린 규칙(config.trial, 엔진이 강제) + 도입 대사. 별 셋(승리/10점 차/20점 차 또는 조기 종료, gsg.trials). ISO 주 해시로 '이번 주의 시련' 표시. 메인 '시련' 버튼(기록 1판 이상). 이어지는 캠페인 보상은 보류.
