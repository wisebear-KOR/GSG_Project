# #092 두 갈래 해석 (다시 해석 시 둘 중 선택)

- 관점: 언어
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
다시 해석이 무작위 재추첨이 아니라 "이렇게도 저렇게도 읽히옵니다" 중 고르는 확정의 순간이 된다.

## 구현 메모
다시 해석 요청 시 readings 2개 스키마. 석판은 첫·둘째 매치 규칙. 두 카드 나란히.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **병합 — #099 「되묻기」**

다시 해석하면 이전 해석과 새 해석을 나란히 놓고 고른다(스키마 변경 없음).
