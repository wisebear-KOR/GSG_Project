# #080 침묵도 계시다

- 관점: 언어
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
말하지 않는 선택까지 말이 된다. 대기 없는 장이 생겨 리듬도 좋아진다.

## 구현 메모
빈 계시·말줄임은 LLM 없이 처리: 1회 전원 기도, 2회 동요, 3회 "신이 떠났다" 사건. 현재 침묵 버튼과 통합.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 (단순)**

빈 계시·말줄임은 침묵과 같게(LLM 호출 없음). 연속 침묵: 1회 자동 노동이 기도 먼저, 2회 신앙 수입 -1, 3회 신도 1명이 율법파로. 말하면 0. 첫 판은 문구만.
