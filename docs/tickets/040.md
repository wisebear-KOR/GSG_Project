# #040 성구 인용 사슬

- 관점: 언어
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
예전 계시의 단어를 다시 쓰면 교리의 일관성에 감동해 보너스. 앞뒤가 맞는 경전을 쓰고 싶어진다.

## 구현 메모
이번 계시와 이전 계시의 2자 이상 명사 겹침 검사 → "인용" 표시와 신앙 +1(연속 최대 +3). 두루마리에 점선.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **단순화**

직전 3장 계시와 2자 이상 명사가 겹치면 인용 → 계시 비용 1로 고정(긴 계시도). 신앙 보상·연속 보너스 없음. 봉인된 말은 인용으로 치지 않음. 원문 점선 밑줄, 비용 알약 "인용 · 신앙 1".
