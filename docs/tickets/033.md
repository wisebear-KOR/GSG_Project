# #033 역전 장치: 신의 분노

- 관점: 시스템
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 완료

## 왜 재미/중독성
승점이 벌어지면 남은 장이 확인 절차가 된다. 지는 쪽의 강한 선택지로 끝까지 역전 가능성을 살린다.

## 구현 메모
적과 6점 이상 차이 나면 wrath +1(최대 3). 기적 비용 -wrath, 3이면 전용 기적 "심판의 날".

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현**

4장부터 장이 끝날 때 6점 이상 뒤지면 분노 +1(최대 3), 3점 이하로 좁혀지면 감소. 기적 비용 -분노(최소 1). 분노 3이면 숨은 기적 "심판의 날"(비용 0: 적 수도 -1, 적 신도 -1) 등장, 쓰면 분노 0. 튜토리얼 제외. 카드 비용에 취소선.

## 구현 기록
장 기록 때 4장부터 6점 이상 뒤지면 분노 +1(최대 3), 3점 이내면 -1. miracleCost = 비용 - 분노(최소 1), 카드에 취소선. 분노 3이면 숨은 기적 '심판의 날'(무료: 적 수도 -1·신도 -1, 분노 0). 분노가 오를 때 붉은 연출.
