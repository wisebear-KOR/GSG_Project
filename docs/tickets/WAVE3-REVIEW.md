# 3차 웨이브 검토 요약

두 관점의 서브 에이전트(밸런스·플레이어 경험·서사, 기술 설계)가 #052~#077을 검토했다. 게임이 이미 촘촘하므로 겹치는 것은 합치고, 검증 비용이 큰 것은 미뤘다.

## 병합
- #052 + #054 → 율법 석판과 성지 (새 승리 조건은 이것 하나)
- #057 + #067 (+#019) → 발견지 확장: 오아시스, 채석장, 전생 유적
- #058 + #059 → 두 갈래 사건 (버튼이 기본, 계시로도 답한다)
- #062 + #065 → 이름 있는 신도와 성인
- #063 + #040 + #042 → 성언은 인용의 승격판, 숨은 낱말은 업적
- #064 + #061 → 영원한 계명 (서원 구조 재사용)
- #068 + #071 → 경외와 은사

## 보류 (4차 이후)
#066 성유물, #074 보드 레이어(→ #098), #076 적 교단, #077 캠페인(→ #094와 함께)

## 원칙
- 확인 화면에 줄을 늘리지 않는다: 감지된 말투·이름·예언·기적·계명은 태그 한 줄에 모은다.
- 첫 판 보호에 추가: 석판, 소명, 2·3막 규칙, 두 갈래 사건, 계명, 성언, 은사.
- 규칙이 바뀌면 같은 시드의 결과도 바뀐다: 판 기록과 최고 기록에 규칙 판(RULESET)을 남긴다.
