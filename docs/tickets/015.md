# #015 말씀이 가리킨 곳 (단어→행동 연결선)

- 관점: 언어
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
계시 속 "분노"라는 단어에서 빛줄기가 적 마을로 날아가면 말과 결과의 연결감이 바로 생긴다.

## 구현 메모
스키마 orders를 {id, word}로 확장(word는 계시 부분 문자열, 엔진이 includes 검증). 석판은 매치된 키워드. 확인 창과 빛기둥 단계에서 단어→타일 곡선.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현 — 스키마 변경 없이**

orders를 {id, word}로 바꾸지 않는다(지연 +0.5~1초). 엔진 linkWords가 석판 규칙·지형명·이름·신학 노트로 단어를 찾는다. 확인 창 칩에 "← '분노'" 태그와 순차 연결선(최대 3).

## 구현 기록
interpreter.linkWords(이름 → 신학 노트 → 석판 규칙 → 지형명). 스키마 변경 없음. 확인 창 원문 밑줄, 칩에 ← '낱말', fx.linkCurve로 낱말→칸 빛줄기 최대 3개.
