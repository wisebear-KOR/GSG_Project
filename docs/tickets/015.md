# #015 말씀이 가리킨 곳 (단어→행동 연결선)

- 관점: 언어
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
계시 속 "분노"라는 단어에서 빛줄기가 적 마을로 날아가면 말과 결과의 연결감이 바로 생긴다.

## 구현 메모
스키마 orders를 {id, word}로 확장(word는 계시 부분 문자열, 엔진이 includes 검증). 석판은 매치된 키워드. 확인 창과 빛기둥 단계에서 단어→타일 곡선.
