# #089 교리 분열 (시즘)

- 관점: 서사
- 규모: M · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
상반된 교리를 둘 다 깊이 쌓으면 교단이 갈라진다. 일관성 없는 신의 서사적 대가이자 고통스러운 선택.

## 구현 메모
대립 쌍이 모두 3 이상이면 분열 사건: 한쪽 포기 / 분파 독립(중립 세력) / 두 교리를 품는 화해의 계시.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **병합 — #093 「분열의 예언자」**

중립 분파 세력은 만들지 않는다. 갈림길 하나로.
