# #055 비밀 예언 목표 (시작 때 셋 중 하나)

- 관점: 시스템
- 규모: M · 우선도: 4 · 웨이브: 3차 — 우선도 4, 중간 이상
- 상태: 대기

## 왜 재미/중독성
승리 경로가 한쪽으로 몰린다. 판마다 다른 방향과 초반 계시의 이야기를 준다.

## 구현 메모
PROPHECIES 10장(8장까지 마을 4개, 번개로 성벽 2개 등). 달성 시 승점 +6과 보너스. 판 시작에 3장 중 1장 선택.

## 검토와 결정
3차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **단순화 — 「소명」, 두 번째 판부터**

판 시작에 소명 3장 중 1장 선택(시드 해시), 달성하면 승점 +5. 예: 8장까지 마을 4 / 개종 3 / 교리 하나 6칸 / 6장까지 신전 3단계 / 굶주림 없이 끝 / 수도 내구도 3 유지. 계절 카드 아래 작은 카드.
