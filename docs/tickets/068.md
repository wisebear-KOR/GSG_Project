# #068 신격 레벨 (경외 누적)

- 관점: 리텐션
- 규모: M · 우선도: 4 · 웨이브: 3차 — 우선도 4, 중간 이상
- 상태: 완료

## 왜 재미/중독성
져도 무언가 남는 안전망. 수치 강화 대신 선택지를 넓혀 공정성 유지.

## 구현 메모
판 종료 시 경외(승점+승리+업적) → gsg.meta.level. 레벨마다 기적·신격·지도자 해금. 메인 상단 진행 막대.

## 검토와 결정
3차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — #071과 병합 「경외와 은사」**

경외 = 승점 + 승리 10 + 새 업적당 3. 레벨 기준 20/50/100/160/240. 레벨마다 은사 하나와 칭호. 메인 화면 「경외 Lv.3 · 다음: …」.

## 구현 기록
경외 = 승점 + 승리 10 + 새 업적×3(gsg.awe), 레벨 20/50/100/160/240, 칭호 6단계, 메인 화면 경외 막대. 은사 4종(설교자: 첫 개종 전까지 선교 +1 / 석공: 첫 신전 돌 -1 / 곳간: 시작 식량 +2 / 눈 밝은 자: 시작 시야 3칸)을 레벨마다 해금, 설정에서 하나 선택(오늘의 계시·도전·튜토리얼 제외). 종료 양피지에 경외 증가와 새 칭호.
