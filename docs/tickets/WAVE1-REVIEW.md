# 1차 웨이브 검토 요약

세 관점의 서브 에이전트(밸런스·시스템, 플레이어 경험, 기술 설계)가 #001~#029를 검토했다. 티켓별 결론은 각 티켓의 "검토와 결정"에 있다.

## 공통 원칙
- **은총 한도:** 청원·말투·이름 붙이기에서 오는 신앙은 한 풀로 묶어 장당 +1까지. 예언은 별도로 기대 수입 장당 +1 이하.
- **교리 가속원**(비유 말투, 첫 이름, 정경)은 해당 교리가 3 미만일 때만 동작 → 궁극 특전(6칸)은 빨라도 8장 이후.
- **대성당 신앙 비용 11 → 13** (신앙 유입 증가 보정).
- **종료 화면은 하나의 양피지**: 역사가(에필로그) · 기록(그래프·TOP3) · 경전 탭, "다시 하기"는 항상 보이게.
- **한 단계에 새 요소는 둘까지**, 세라 말풍선·새 배너는 장당 하나.
- **첫 판 보호:** 금지어 율법, 편향된 사제, 기적 드래프트, 정경 봉헌은 두 번째 판부터.
- **스키마는 바꾸지 않는다.** 말투·이름·예언·단어 연결·교훈은 모두 엔진 정규식으로 → 석판 모드와 LLM 모드가 같게 동작하고 지연이 늘지 않는다. 프롬프트에는 입력 줄(율법파 의도, 신학 노트, 사제 성향)만 추가.
- **결정론:** 난수를 덱 흐름과 주사위 흐름으로 나누고 덱을 미리 나눠 둔다. 연출용 선택은 해시로. 발견지 배치는 별도 난수.
