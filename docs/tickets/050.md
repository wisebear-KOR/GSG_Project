# #050 교리 특전 해금 연출

- 관점: 손맛
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
특전 해금이 조용히 지나간다. 카드가 튀어나오는 순간이 교리를 쌓을 동기가 된다.

## 구현 메모
재생 끝에 새로 넘은 특전 감지 → perkReveal 카드 뒤집기와 빛, sfx.holy.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현**

재생 끝에 2·4·6칸을 새로 넘었는지(또는 8장에 궁극이 깨어났는지) 감지 → 카드 뒤집기 연출(장당 하나). 8장 전 6칸이면 "궁극 — 8장에 깨어난다".
