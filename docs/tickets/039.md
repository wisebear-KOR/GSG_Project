# #039 거룩한 오역

- 관점: 언어
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
엉뚱한 해석이 짜증이 아니라 "기이한 계시" 보너스 이벤트가 된다. 오해가 이야깃거리.

## 구현 메모
단어-행동 불일치 또는 reading=기이일 때 "기이한 해석" 배너와 작은 축복. 연대기 "신께서 '물고기'라 하셨으나 사제는 '기도'로 들었다".

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **단순화 — #007 판결에 병합**

LLM 해석만(석판은 어긋나지 않음). 명령 행동이 있는데 단어 연결이 0개이고 석판 해석과 겹치는 행동도 없으면 "기이한 해석" 도장, 판당 1회 은총 +1(풀 안). 연대기 "신께서 ○○라 하셨으나 사제는 ○○로 들었다".
