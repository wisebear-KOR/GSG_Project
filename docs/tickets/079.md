# #079 신의 피로 (쓸수록 비싼 기적)

- 관점: 시스템
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 폐기

## 왜 재미/중독성
같은 기적 반복을 막고 "아껴 둔 번개를 쓸 때"라는 타이밍 결정을 만든다.

## 구현 메모
castMiracle에서 사용 횟수만큼 비용 +1, 3장 쉬면 -1. 카드에 현재 비용.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **폐기**

기적은 장당 1번·드래프트·분노 할인까지 이미 세 겹이다. 한 기적 사용률이 50%를 넘는 플레이테스트 결과가 나오면 「직전 장에 쓴 같은 기적 +1」로만 되살린다.
