# #081 전설이 된 땅 (별칭)

- 관점: 언어
- 규모: S · 우선도: 3 · 웨이브: 4차 — 우선도 3과 대형
- 상태: 대기

## 왜 재미/중독성
큰일이 난 칸에 "분노의 숲", "첫 기도의 언덕" 같은 별칭이 붙어 지도가 내 말의 역사책이 된다.

## 구현 메모
계시로 명령된 행동이 점령·개종·대성당을 낸 칸에 교리 형용사+지형 별칭. 호버 시 계시 원문 인용.

## 검토와 결정
4차 웨이브 검토(밸런스·플레이어 경험·서사, 기술 설계) 결론: **구현 — #005 이름과 공존**

계시로 명한 행동이 점령·마을 개종·대성당 완공을 낸 칸에 교리 형용사+지형 별칭(분노의/빛의/넘치는/별의), 판당 3개, 이름 붙인 칸·성지 제외. 툴팁에 원문 인용, 에필로그에 나열.
