# #045 도전 링크 (시드 URL)

- 관점: 리텐션
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 완료

## 왜 재미/중독성
"이 맵을 이겨 봐" 링크 하나로 비동기 경쟁이 성립한다.

## 구현 메모
?seed=&size=&diff=&target= 파라미터 → 설정 적용과 목표 표시, 종료 시 판정. 공유 버튼이 URL 생성.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현**

?seed=&size=&diff=&target= → 설정 덮어쓰기(저장 안 함), veteran 고정·정경 없음으로 같은 판 보장. 시작 배너 "도전: 승점 N을 넘어라", 종료 "도전 성공/실패". LLM 해석은 비결정적임을 명시.

## 구현 기록
?seed=&size=&diff=&target= → 설정 덮어쓰기(저장 안 함), veteran 고정·정경 없음으로 같은 판. 시작 버튼 '도전 시작 · 승점 N을 넘어라', 부제, 종료 시 도전 성공/실패. 종료 양피지 '시편 복사': 결정적 장의 계시·대사제 외침·결과·칭호·도전 링크(내 승점 목표) 텍스트.
