# #037 말씀의 연속성 (같은 교리 3연속 기적)

- 관점: 시스템
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 대기

## 왜 재미/중독성
계시가 흩어지면 이야기가 없다. 같은 교리를 세 장 이어 말하면 작은 기적이 터진다.

## 구현 메모
최근 3계시 교리가 같으면 즉시 효과(평화: 적 1명 개종 / 전쟁: 적 성벽 파괴 / 풍요: 식량 +4 / 지혜: 시야 +1). 빛기둥 재사용.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **구현**

같은 교리 3장 연속이면 즉시 발동 후 카운터 0. 교리 칸은 주지 않음(궁극 시점 불변). 평화: 적 1명 개종 / 전쟁: 가까운 적 성벽 파괴(없으면 적 신앙 -2) / 풍요: 식량 +4 / 지혜: 둘레 2칸 안개 걷힘+발견. 교리 메달에 연속 점 ●●○.
