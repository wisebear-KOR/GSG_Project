# #005 이름 붙이기 의식

- 관점: 언어
- 규모: S · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 대기

## 왜 재미/중독성
"이 강을 요단이라 부르라"면 지도에 이름이 새겨지고 이후 "요단으로 가라"가 통한다. 세상을 말로 만드는 쾌감.

## 구현 메모
정규식 (X)을 (Y)라 부르라 → 가장 가까운 해당 지형 칸에 state.names. tileName이 우선 사용(프롬프트에도 반영). 손글씨 라벨. 신앙 +1, 지혜 +1.
