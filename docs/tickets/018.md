# #018 사제의 신학 노트 (학습하는 해석)

- 관점: 언어
- 규모: M · 우선도: 5 · 웨이브: 1차 — 우선도 5 (핵심 재미)
- 상태: 완료

## 왜 재미/중독성
사제가 "'바람'이라 하시면 탐험을 뜻하신다"를 배워 나만의 은유 언어가 통하게 된다.

## 구현 메모
수락된 계시의 핵심어→행동 유형을 state.lessons에 저장, 최근 3개를 프롬프트에. 석판은 TABLET_RULES보다 먼저 조회. 신학 노트 서랍.

## 검토와 결정
1차 웨이브 검토(밸런스·플레이어 경험·기술 설계) 결론: **구현**

교훈 최대 3개(오래된 것부터 교체), 기본 키워드(기도 등)는 잠금. 첫 기록 때 알림, 연대기 서랍 "신학 노트"에 "잊게 하기".

## 구현 기록
LLM 해석을 수락할 때 석판 규칙에 없는 명사가 행동을 불렀으면 extractLesson → state.lessons(최대 3). 프롬프트 '신의 말버릇' 줄, 석판이 규칙보다 먼저 조회. 사제 말풍선으로 알림, 연대기 서랍 '신학 노트'에 잊게 하기.
