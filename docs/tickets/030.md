# #030 선공 표시와 선제 차단

- 관점: 시스템
- 규모: S · 우선도: 4 · 웨이브: 2차 — 우선도 4, 작은 것
- 상태: 완료

## 왜 재미/중독성
같은 칸 충돌 규칙은 있지만 보이지 않는다. 의도가 보이면 "그 칸을 먼저 차지해 막는다"가 핵심 수가 된다.

## 구현 메모
상단에 이번 장 선공 배지. 적이 노리는 칸의 행동 설명에 "(율법파가 노리는 칸 — 선공이면 막는다)". 짧은 계시(30자 이하)면 다음 장 선공 보상 검토.

## 검토와 결정
2차 웨이브 검토(밸런스·플레이어 경험, 기술 설계) 결론: **단순화**

새 규칙 없이 기존 충돌 규칙을 드러낸다. 의도 칸 툴팁·율법 카드 뒷면·확인 칩에 "선공 — 이 칸에서 움직이면 막는다"(율법파 선공이면 "빼앗긴다"). 짧은 계시 선공 보상은 보류(거의 모든 계시가 30자 이하).

## 구현 기록
새 규칙 없이 가시화: 의도 칸 툴팁과 확인 칩에 '선공 — 율법파를 막는다' / '율법파 선공 — 빼앗긴다'.
